# 项目设计与路线

## 目标与当前状态

Mirage · 浮城是面向数据中心的三维数字孪生个人项目。目标是把现实基础设施的空间、结构、连接与运行变化组织为可探索的数字世界，同时积累三维图形、领域建模、模型流程、实时数据与性能工程经验。

面向希望理解机房及设备运行的体验者、开发者和运维人员。项目独立设计，不限定于某个厂商、某种设备或特定管理系统；服务器与超节点按各自结构处理。

当前已完成机房 → 机柜 → 设备 → 部件的本地浏览链路，含镜头控制、结构展开复原、自动巡游和共享时钟的温度、功耗、运行状态与告警。八机柜包含 1U/2U 计算、接入交换机和双控存储，交换机和 4U 存储已换用保留贴图的贡献外观，内部仍为独立配置示意；机型分别维护部件契约与可选配置；明确配置中的维护部件都有可选择几何。顶置交换机与后置 PDU 按安装约束布置，端口和 U 位做唯一性/冲突校验。趋势与时间控制按需打开，数据来源统一说明。运行方式、配置规模和限制集中见 [README](../README.md)。宏观入口、真实数据接入、完整网络拓扑及上游供电系统尚未实现。素材与许可集中见 [资产说明](../assets/README.md) 和 [许可范围](../LICENSE-ASSETS.md)。

## 体验范围

空间路径：**地球 / 园区分布 → 园区 → 建筑 → 楼层 → 机房 → 机柜 → 设备 → 部件**。

建设顺序由内向外：先精修一套完整机房，再形成单园区，最后扩展多园区与地球入口。地球展示已配置园区及可追溯汇总，不加载所有园区的设备细节；地域筛选属于分布入口，不作为必须经过的空间层级。

| 方向 | 目标 |
| --- | --- |
| 空间浏览 | 园区分布、建筑分层、机房布局、墙体门窗、通道、制冷与配电设施；逐层进入、返回、旋转、缩放与聚焦 |
| 结构探索 | 机柜前后视角与开合、U 位安装、设备抽出/开盖、部件高亮、爆炸展开与复原 |
| 关系查看 | 网络端口与链路、供电与冷却关联、超节点成员；与物理位置联动 |
| 运行状态 | 功耗、温度、健康状态、指标趋势、告警发生与恢复；搜索和告警可直接定位 |
| 时间回放 | 场景暂停、重置、回看及重复运行，三维、拓扑和图表时间一致 |

地球、地图、地形与园区坐标资源使用前核实来源、许可与适用要求，遵循现有资产规则。没有可用数据时使用明确标记的示意位置，不把虚构园区当作真实地点。

## 第一条完整链路

以当前机房为样板，精做建筑空间、机柜、四种已有设备及维护部件，再向一栋建筑和一个园区扩展。每个层级都要有完整的进入、操作、数据表达与返回体验。当前贯通的模拟场景继续作为设计验收主线：

**冷却能力变化 → 温度响应 → 告警触发 → 定位设备 → 查看趋势与关系 → 恢复回放。**

使用固定种子、有版本的场景与事件序列；其他对象用统一风格的原创简化资源。模拟规则和延迟明确记录，不宣称是精确热流体仿真或故障预测。超节点可作少量关系叠加或后续专题，不阻塞首条链路。

初期不连接实际管理系统，不执行远程开关机或配置变更。真实数据源从后续只读适配开始，单独记录验证范围。

## 下一轮体验设计（设计评审中）

本节记录已落地的统一工作区与后续设计基线。默认入口已整合资源定位、数据图层、对象操作、时间分析和自动巡游，只保留一个正式入口。后续环境能力继续按本节逐步实施，名称与布局通过实际画面打磨；不因新增指标继续增加同级页签，也不在页面预留尚不可用的入口。

### 界面开发基线（已确认）

当前场景工作台已确认作为正式开发基线，后续继续在这一套布局上完善，不重新设计一套界面。已接入默认工作区并保留模拟播放与巡游，再推进温度/气流表达及样板机房完整度；容量、连接与园区尺度仍按后续阶段实施。

- 三维是主体；左侧定位资源，右侧解释所选对象。详情与完整分析互相替换，告警复用资源筛选及空间标记，不恢复常驻底部告警表、时间条与曲线的堆叠。
- 资源行统一为名称及就近状态、类型/位置、横向操作；按钮与名称对齐，普通、悬停、选中和禁用状态均可辨认。预览、定位和进入分别承担明确动作。
- 按桌面工作台设计，优先保证三维视口和鼠标、键盘操作。视图、视角与结构操作留在场景内，控件按可用宽度避让，中等窗口的资源与详情分时占位。
- 指标与状态分开表达，保留单位、范围、数据质量和模拟边界。场景放位置与读数，面板放比较与解释；说明按需展开，不堆重复数字、标题和装饰。
- 场景优先用视觉表达，少用文字覆盖设备。通过局部轮廓、端点、方向箭头、空间刻度与有含义的短促动效呈现选择、关系和变化，让模型与材质形成视觉中心。就地文字限于必要身份、单位与关键读数，随选择或明确查看动作出现；长说明和配置边界进入右侧详情或按需展开。炫酷感不能依赖遮挡设备的文字卡、泛光或密集粒子，也不能仅靠颜色和动画传递信息；暂停、减少动态效果及键盘操作时仍可理解和查阅。
- 时间分析围绕当前对象，入口、播放状态、场景同步与返回路径清楚；回看保留镜头与结构姿态。新能力先融入现有模块，不以新增同级页签替代信息组织。
- 标签和关系清单按当前任务出现。总览默认仅标所选对象，不叠加告警卡或状态图例；设备内部默认仅标所选部件，模型评估留在资源状态与详情。温度、功耗保留必要读数，气流与主动追踪端点优先，避免同一部件重复贴名；选中标签就近避让并以引线关联原位置，需要时从“显示”补充标签。详情顺序固定为身份/异常 → 指标 → 小趋势 → 按需展开的关系与配置，不让长端口表将趋势挤出首屏。
- 常规界面验收以 1440×900 桌面视口为主，以 1024×768 中等窗口为辅。在实际页面核对涉及的机房、机柜、设备/部件及告警/分析组合，并保存关键交互截图。保留已有手机布局。手机专用布局、触控交互及 390px 截图不列入常规开发与验收范围。

### 本轮设计收敛与待实施重点

本轮决定先完成场景表达与工作区精修，再推进容量与更大尺度。技术链路可用不等于视觉验收完成。以下为待实施设计，不表示当前页面已经达到目标。

首批精修已落地：资源导航收起按钮位于栏内标题右侧，收起后从场景工具栏左端的“资源”入口展开；页头只保留空间路径。展开时聚焦搜索，关闭后焦点返回入口，窄屏支持 Esc 收起导航，搜索条件与对象选择保留；进入对象保留桌面导航选择；温度图例压缩至场景下沿。气流使用具有实体宽度的送风线、分段回风线与更清晰的方向箭头，保留暂停、过期静态与真实遮挡。门禁读卡器、两处烟感、两处墙柱环境探头，以及漏水检测控制器和感应线已支持独立选择、查找和定位，仍为未接入监测的布置示意。气流端点标签与格栅配置已补齐（见下文）；建筑遮挡已增加自动剖切；建筑背景材质已收敛（见下文）；通道比例、设施关系及其余关键画面仍待精修。

**规模先保持，完整度先提升。** 当前 14×12 米、8 柜、84 台设备作为样板与回归基线。暂不通过加柜、复制设备或扩大空地制造规模感；只有新增系统、合理通道或服务空间确实需要时才调整尺寸。扩展前先验证不同朝向、不同机房配置和对象 ID 的复用，避免把当前同向双排布置写死成通用机房。

**气流必须可辨认。** 当前已用就地标签标明端点，并收敛一条完整代表路径：制冷单元送出 → 地板送风位置 → 目标设备进风 → 柜后回风假设；用具有可见宽度的流带、间隔明确的方向标与短脉冲表达流向。送风与回风通过色彩、实虚和端点共同区分；暂停时仍能读出方向。只在端点附近给出“送风 / 进风 / 回风假设”和当前有效读数，选中后强调该支路，其余减弱。当前维持温度视图内的气流入口、默认展示与交互，后续内容扩充后再评估独立视图。当前室内总览只显示一条代表支路；需要时选中其他机柜或设备切换，不同时铺开多条路径。不得用整场泛光、铺满粒子或关闭所有深度遮挡补救可见性，也不把线宽或运动速度解释成未定义的风量。

**场景承载位置与数值，面板承载比较与解释。** 温度放在切片、测点及对象附近；功耗放在柜侧标尺和已定义供电支路；容量放在空闲 U 位；告警放在异常对象和独立告警入口。关键数字必须有单位、对象和数据质量，精确值随选中显现；三维负责发现，曲线负责时间比较，列表负责检索。取消重复 KPI、长标题、常驻说明和重复操作；来源、模型边界与配置折叠查看。信息移入场景后仍要有键盘可访问的对象详情，不能只依赖悬停、颜色或动画。

**视觉目标是精致的基础设施作品。** 保留金属、PCB、线缆与建筑的材质层次，降低地板重复纹理、墙体和桥架对主体的争抢；根据视角处理遮挡，选中与展开对象形成清晰视觉中心。科技感来自可解释的流向、空间刻度、切片和时间变化。数据颜色与状态颜色保持独立，不让所有正常设备发光，也不以满屏标签增加信息感。

机房背景已降低地板重复细节、墙面与桥架的反光对比。地面保留 0.5 m 分格，以连续表面和低对比程序纹理替代逐块实体地砖；纹理随观察距离平滑过滤，避免远景接缝形成细碎噪点。地面顶高、格栅、通道、设施位置与照明强度沿用原配置；墙体、框架和吊装结构分别配置颜色、金属度与粗糙度。地面分格属于外观表达，不表示已建模可拆地板、架空送风层或真实材质参数；标准渲染和细节阴影共用同一表面定义。

空间标记按视图区分含义：总览只看原始模型、结构与选择；温度只表达温度和代表气流；功耗只表达负载与供电配置；告警只呈现实际设备告警。青白短角标表示选择，切换选择或主动聚焦时只做一次短促收拢，回看不重播，减少动态效果时立即静止。告警以局部三角/菱形区分预警/严重，不再同时叠整柜染色和多张状态文字卡；其他视图不铺状态符号或状态图例。标记保留深度遮挡，身份、数据质量与当前状态仍可从资源及所选对象详情查阅；设备内部不自动散布模型评估点或线框。机柜通道标签只保留方向和尺寸，预留边界在图例集中说明。

机房已支持默认开启的自动建筑剖切：以相机到机柜中部与顶部代表点的视线，检查两面墙、两段桥架和三条吊灯的包围盒，整段剖切挡路的背景结构，移开视角后恢复；边缘保留少量退出余量以减少反复闪现。墙上门禁和环境探头随所在墙剖切；选择设施时改用设施位置判断遮挡，并保留其安装墙面，地板、机柜、设备、气流及照明强度保持原有定义。可从“显示 → 自动建筑剖切”恢复完整建筑；机柜及设备层级禁用此选项，返回机房保留偏好。它是当前静态样板的观察辅助，不是逐像素遮挡判断或真实建筑改动；通道尺寸与完整建筑设施校准仍未完成。本轮已在本机 Chromium 检查桌面、窄屏的开关、旋转、层级往返及气流/设备/告警/分析组合，无新增数据或监测能力。

机房“显示”工具可临时保存一个当前视角，之后定位设施、切换标准视角或手动旋转，再返回保存的镜头；可替换、重复返回或清除。保存包含相机位置、观察中心与旋转/缩放限制，只恢复镜头，不恢复对象、图层、模拟时间或建筑剖切偏好。镜头与结构未就绪时禁用保存/返回。离开机房、载入固定演示画面、重建场景或视口宽高变化（包括侧栏变化）清除保存，避免将旧取景应用到不同画幅；不跨刷新持久化。本机 Chromium 已在 1440×900、1024×768 检查设施近景往返、替换与重复返回、共享时间保持、窗口尺寸变化、主动清除及离开机房后的清理。

机房总览选中机柜时，地面显示柜前操作与柜后检修的预留范围，分别为 1.20 m 与 0.90 m 进深、1.00 m 宽，尺寸集中在场景 JSON；选中时收起重复的机房运行概览，标签跟随投影并避让控件，现有“配置与数据说明”提供可用键盘查阅的尺寸与边界。当前按同向 +Z 的柜体位置布置，切换机柜更新范围，进入机柜、设备或温度/功耗/告警图层时收起；回看不改变预留配置。图例可主动“对照排间通道”，将本柜的两个范围换成相邻两柜面向通道的预留，并标出两条外边界之间的距离。以 A01、B01 为例，柜面间距 2.50 m，A01 柜后预留 0.90 m、B01 柜前预留 1.20 m，中间相隔 0.40 m。只在同向样板内按柜宽投影和双方唯一对柜的位置配对。“俯看两柜”可一次取景两柜，详情的“排间对柜”可预览或定位对侧。换边预览与回看保留对照；切换其他图层或进入机柜结束对照。自动检查仅核对与已定义柜体、设施平面位置的关系，以及当前门扇和导轨抽出投影，不代表实测净距、完整施工障碍物、人员作业条件或工程验收；通道比例与完整建筑设施仍待完善。

机柜前置盲板按本柜设备安装区间生成，不再以全机房 U 位并集判断空位；1U/2U 服务器、交换机和 4U 存储分别按完整占用跨度避让。当前计算柜 26–27 块、混合存储柜 18–19 块 1U 实体盲板，两端固定点和板间接缝用于区分封板与设备，不增加场景文字、状态灯或独立资源。机房克隆柜与活动柜使用各自的实例矩阵，切柜、抽出与回看不改变安装定义；抽出中的设备原 U 位保持开放。柜体及门框高度同步校准，为 U42 留出顶部空间，设备 U 位和安装高度不变。配置说明可查封板范围；当前是安装封板示意，未定义预留、不可用空间或容量分配，也不据此推断实测气密性或温度改善。

机柜资源导航默认提供按 U 位从上到下排列的安装图，可切回原列表；机房与设备内部仍沿用资源列表。1U/2U/4U 设备保持完整安装跨度，连续封板保留逐 U 分格，后置 PDU 独立列为 0U 附件。搜索、类型与告警筛选淡化不匹配对象而不压缩物理位置，U 位查询强调对应刻度；跨柜结果可转回列表继续定位。选择联动对象详情与三维标记，明确定位或查看设备才移动镜头；抽出的设备在图中保留原安装位，进入内部与返回沿用结构归位。温度、功耗和告警只显示各自口径，过期、未配置、离线及停机零功耗分开，共享时间回看不改变安装分布。安装图支持方向键、Home/End 与 Enter，选中项自动滚入导航可见区；中等窗口预览保留导航，通过详情或定位切回对应区域。它是安装配置检视，不提供容量分配、预留或不可用状态。本轮在 1440×900、1024×768 的本机 Chromium 检查八柜、四种机型、搜索筛选、回看、PDU 定位和普通动画往返。

两处固定环境探头的演示采样集中在场景 `environmentMonitoring`，沿用现有位置与安装高度。每 4 秒采样，温度与相对湿度分别判断质量；最后采样超过 8 秒过期。第二探头包含首次缺样、湿度断采与整机离线窗口；缺失、过期和离线均无当前值，最后观测另列，零值不当成缺失。温度视图的“环境测点”可预览和定位两处探头；选中后仅标记局部温湿度，收起设备进风切片、色条与气流，返回设备进风恢复切片配置。详情与时间分析使用同一 120 秒时钟，曲线只绘制已发生的观测，回看保留镜头；这些点位读数不参与 84 台设备的进风、功耗或告警汇总，也不插值为整间机房环境场。 时间分析中的“数据质量过程”按时刻合并温度、湿度及露点推导可用性的变化，可筛选指标、点击或用键盘回看并返回开始回看时的秒数。初始状态单列，正常采样不重复生成事件，只显示当前秒之前的已知变化；第 52 秒的采样不同步与第 57 秒的湿度过期分开记录，不归为设施告警。已在 1440×900、1024×768 验证筛选、键盘回看、时间往返及镜头保持。

环境详情与分析可按需展开两点对照，并列所选与另一探头的位置、配置高度、读数、质量和采样秒。差值按“所选 − 对照”计算，仅使用两侧同一采样时刻的有效值；湿度差单位为百分点，露点差仍来自推导。缺失、过期、离线或采样不同步逐指标留空，不使用最后观测补差值。分析悬停时对照跟随游标秒，预览与定位仍保留共享场景时间；切换探头后反转对照方向，详情/分析往返保留展开，载入演示画面重置。对照不表示区域梯度、异常阈值或凝露风险。本机 Chromium 已验证 1440×900、1024×768 的有效/不同步/离线、预览镜头保持、定位与分析往返。

露点采用 [NPL 的水面 Magnus 近似](https://www.npl.co.uk/resources/q-a/dew-point-and-relative-humidity)反解，由同一探头、同一采样秒的有效温湿度推导，系数为 17.62 和 243.12°C。本演示仅在温度 0–60°C、0<RH≤100%、推导结果不低于 0°C 时显示；输入不同步、无效或超范围均不推导，不提供霜点。露点不是独立测点，没有表面温度或环境阈值，不提供凝露判断或独立告警。环境测点仍是演示序列，未接入真实数据。后续先补有明确来源和范围的监测配置，再考虑区域覆盖与更大尺度。 回归可用第二探头：第 12 秒缺失、52 秒采样不同步、60 秒湿度过期、100 秒离线、112 秒恢复。本机 Chromium 已检查 1440×900、1024×768 的预览/定位、小趋势、曲线与键盘回看、图层切换、切片配置往返，以及普通动效下从展开设备安全归位到测点。

PDU 插座核对与设备输入支持按需追踪，一次只显示一条已配置支路；列表保留预览操作，从列表开始追踪不改变选择、镜头或模拟时间。场景框选对应 PDU 配置插座，并以较细静态线连接设备代表输入，设备内部只标记本端电源部件；未连接插座不生成支路。切换温度、总览或告警收起供电标记，返回功耗可继续；同一关系的设备/PDU 往返保留追踪，选择无关对象、取消或载入演示画面清除。回看与展开保留追踪，跨设备定位沿用安全归位。桥架、探头、检漏与制冷单元等无供电接入的对象不再借用活动设备的默认支路。追踪后，详情列出同一支路上的配电柜逻辑出线、PDU 插座和设备输入，三处均可预览或定位。设备端同时给出安装 U 位和配置电源部件。定位 PDU 或设备输入会在机柜后侧展示当前接入，从展开设备出发先归位；定位配电柜则回到机房。三维短标只保留当前出线、插座号与输入编号。当前支路可直接查看对应电源部件，依次完成旧实例归位、进入目标整机与展开聚焦；可切换同一设备的 A/B 输入，再沿对应插座返回 PDU 或配电柜。输入切换保留结构与共享时间，必要时详情回到所属整机，明确查看电源才移动镜头。电源部件主动定位从后侧略俯视观察，减少控制器遮挡；手选视角仍可覆盖。部件功耗继续表示模型分项或转换损耗，不代表输入支路计量。配电柜使用共用的逻辑出线代表位置。框标对应本场景 PDU 几何和配置编号，不代表真实插座类型、实际线缆或支路计量，表中功耗仍为关联整机输入。

PDU 详情的“插座逐位核对”按配置高度从 24 到 01 排列全部位置，编号与三维 PDU 几何共用配置。查找编号、设备或 U 位只淡化不匹配项，不重排或缩短插座排布；当前选择仍可查阅。选择已接位置沿用对应配置支路，选择未连接位置清除旧支路并只框选该插座，不生成对端、零功耗、断电状态或可用容量。预览不移动镜头，明确定位切到所属机柜后侧；当前结构不包含该 PDU 时提示定位，不把标记画到其他设备内。

资源导航采用按层列表：机房列机柜与设施，机柜按 U 位从高到低列设备，设备内部按部件类别分组。名称同时显示类型、编号和位置；搜索支持中文类型、机柜、U 位和编号组合。输入安装坐标时按设备占用的完整 U 位区间匹配。例如 `A01 U24` 可找到占 U23–24 的 SRV-01，`B03 U27–33` 可核对该段的设备与前置盲板。机房层可查全室，进入机柜或设备后默认查所属柜，写明柜号可跨柜。定位安装位置会选中所在机柜内的设备并保留查询，从展开设备定位时先归位。装机角标按安装外廓绘制并跟随导轨移动。盲板按配置核对，不计为可分配容量。单击只选中与预览，不移动相机或自动展开；点击行右侧“进入”后进入所在机柜，再查看设备内部；“定位”聚焦可见资源，部件使用定位操作。跨位置预览保持当前模型，切换实例前先让已抽出或展开的设备归位，并等待对应的场景就绪信号。

进风对照可固定一台整机为基准，再选择另一台打开双设备分析。实线表示所查设备、虚线表示基准，两条曲线共用温度刻度、时间轴与游标；量程只取当前秒之前的有效观测，过期和缺失断线。差值固定为“所查 − 基准”，只计算同秒有效整机进风；两端预览不交换差值方向。悬停仅改变游标，两端读数随游标更新，点击、拖动或键盘回看才推进共享场景；共同冷却事件去重，两台设备告警保留各自身份。它不比较部件推导、不新增测点，不以温差判断异常、冷却效果或根因。

双设备分析可分别预览两端、定位安装位或查看机房气流；结构检视及部件选择期间仍明确比较所属整机。预览保持镜头与结构，跨设备定位先归位；返回机房对照恢复原所查设备、查找、滚动和开始比较时的切片，沿用最新共享秒数。“单对象分析”结束此次比较并保留基准，选择无关对象也结束比较；基准可替换或清除，载入固定画面统一清空，不跨刷新保存。桌面验收覆盖两种视口及正常/减少动态效果、跨柜两端往返、游标与键盘回看、过期转折、离线/缺失/停机和展开结构归位。

1U/2U 服务器已支持独立开盖：只移开上盖，其他部件保持装配；展开前自动取盖，合盖前先复原部件。开盖状态随图层、回看和重播保留，返回机柜前先合盖，切换设备不继承开盖姿态。交换机与存储仍使用外观与内部配置示意切换。

已展开的设备支持“只看此部件”：单独显示所选模块及其子件，选择子件则进一步收敛；其余结构、展开引线和连接标记暂隐，原有装配位置、展开比例与材质不变。四种机型沿用各自部件清单，交换机和存储仍明确为内部配置示意。切换部件或前后视会聚焦当前检视对象，切图层及回看保留检视；“显示完整结构”恢复结构与进入前取景，窗口变窄时适配距离。复原、合盖、选择整机、跨设备或返回上级结束检视，旧模型缓存恢复完整。细模加载和重试可在当前部件上继续，不把临时隐藏解释为部件拆除或未安装。桌面验收覆盖四机型模块/子件、部分展开、视角与分析组合、普通和减少动态效果、延迟加载与失败重试。

时间分析已支持同一对象的温度/功耗对照：两条曲线分别标明单位与读数口径，悬停同时查看历史值，点击或横向拖动曲线、选择事件或使用方向键回看，开盖和展开姿态保持不变。鼠标按下即接管播放，拖出图表保留指针捕获并限制在 0–120 秒；同一秒不重复提交，松开或取消后结束回看。触摸区分横向回看与纵向滚动，轻点可跳转，额外触点不接管当前手势；冷却输入与关联进风曲线沿用同一操作。中小窗口载入时间分析预设会收起资源栏，确保分析可见。机房、机柜和设施的分析按来源折叠已知事件，最近有变化的来源排在前面。展开设备可依发生顺序回看预警、升级、降级与恢复，所选时刻显示模拟阈值和持续条件。回看保留当前范围与空间姿态，明确选择“定位”才转到该设备所在机柜并继续设备分析。公共冷却输入单列，部件沿用所属设备事件，数据过期后仍保留此前已知事件。设备与部件的时间分析按共享秒数显示整机进风判定，可查看持续条件的计时、回看条件起点或状态变化，再返回刚才查看的秒数。过期、离线、未配置或停机时说明判定不可用。告警来源可直接查看对应设备的机房气流或安装位，展开设备先归位。部件曲线仍采用该部件的模型口径。本轮已在本机 Chromium 的 1440×900、1024×768 和 390×844 验证拖动、边界、键盘、播放接管、数据空缺与结构姿态，手机手势采用浏览器触摸仿真，未代表实体触屏或其他浏览器验收。

机房、机柜、制冷单元、配电柜与 PDU 已支持按共享时间核对汇总输入。详情的有效覆盖可展开逐台名单，时间分析中沿用同一入口；按已计入/未计入分组，可按设备或机柜查找。进风取有效整机最高值，功耗按设备去重求和；停机零功耗有效，过期、离线、未配置与无进风值分别说明，过期项明确列出最后观测时间及旧值。筛选只影响名单，不改变汇总范围。预览设备保留镜头与结构，可返回原范围、核对指标及查找条件，回看后的共享时间继续保留；手动换对象、主动定位或载入演示画面结束该次预览往返。部件推导不加入输入名单，A/B 不重复计量，设施关联汇总仍不代表设施测点或支路计量。本轮在 1440×900、1024×768 检查五类范围、预览往返、时间回看、键盘收起与展开设备姿态保留。

温度图例中的输入覆盖、设备对照和气流说明共用一组展开状态，一次只展开一项；长内容在各自区域内滚动，保留切片方向、柜排、色阶与位置滑杆。说明内容支持键盘滚动，Esc 收起当前项并返回标题焦点，不关闭右侧详情或分析；展开、收起及切换说明接管巡游，保留所查对象和共享时间。

机房温度图例可按需“对照所查设备”，分别查看整机有效进风和该机柜前方当前切面的局部估计，列出安装 U 位与进风代表高度。选中其他柜排、切面远离设备高度或输入无效时说明对应边界；柜前估计仍可能来自附近其他设备，不能当作所查设备读数。可按现有滑杆步长调整到设备附近：水平切片取邻近安装高度，垂直切片选择所属柜排及邻近进风代表位置的离柜距离；随后可返回原切片设置。对齐不改变选择、镜头或共享时间，回看更新读数，手动改变切片后不再显示旧位置返回入口，切换所查对象结束该次往返。

当前已有机房水平/垂直进风温度切片与气流示意、两处环境探头的温湿度演示与推导露点；安装空间核查已实现，可分配容量和跨柜网络拓扑视图尚未实施。曲线与量程仅使用当前时刻之前的观测；过期与缺失保留空缺，停机零值有效。真实设备接入、浏览器兼容性和性能基准未在本轮扩展。

### 场景、图层与操作

以“对象 × 数据图层 × 时间”组织体验。保留一个连续的三维场景、同一对象选择与共享时钟。结构拆解融入对象操作，不再和运行状态并列为观察模式；默认总览视图保留原始材质与选择标记。机柜开门、设备抽出、开盖、展开与复原随所选对象出现，切换指标后仍可操作。温度与功耗视图直接呈现各自指标。

主入口使用直接、可验证的名称，暂不以未实现的能力概括现有数据：

| 入口 | 回答的问题 | 当前范围 |
| --- | --- | --- |
| 总览 | 当前有什么、在哪里、内部如何组成？ | 机房与机柜浏览、资源预览、设备结构及对象操作 |
| 温度 | 哪里温度较高？ | 设备进风与部件模型温度，分别标记数据口径 |
| 功耗 | 当前用了多少电、占预算多少？ | 输入功耗、已知汇总与预算占比，不推断上游电源关系 |
| 告警 | 哪些对象异常、在哪里？ | 与温度、功耗同级的场景与告警列表，支持筛选、选中和定位 |

门开、维护、离线、数据过期分别表达，不统一算作故障。总览为默认入口，缺少的房间环境测点不沿用到部件；模型部件评估不进入设备告警计数。

### 布局与信息取舍

- 左侧承担资源查找与进入：一层一列表，搜索与类型筛选保持固定；选择、定位与查看内部各自明确，次级部件分组折叠。
- 中间以三维为主：图层选择与对象操作分组，图例跟随当前指标；标签按距离、选择和异常优先级显示，处理碰撞、遮挡与画面边界。
- 右侧为可收起的所选对象详情：对象身份、当前图层关键值与小趋势在前；配置和数据质量按需展开。默认机房读数进入场景，减少重复内容和常驻面板。
- 时间分析按需展开：从对象小趋势或事件进入，关闭后恢复场景空间。来源与模拟边界保留在统一说明和可查看的数据详情中。
- 按界面开发基线的视口检查首次加载、长名称、滚动、展开面板与错误状态，确保控件可见且可操作。

### 三维表现与数据含义

真实金属、塑料、PCB 与建筑材质形成底层质感；界面使用低亮度中性底色、清晰文字和少量强调色。运行状态色与指标色阶分开：正常、预警、严重通过颜色、形状和文字共同表达；高功耗或热图暖色不直接等于故障。具体色值先在真实场景中比较，再固定为统一设计变量。

| 维度 | 三维表现方向 | 约束 |
| --- | --- | --- |
| 温度 | 设备表面热图、可移动水平/垂直切片、热点定位 | 进风、排风与部件温度分开；测点、插值和模型推导有可查依据 |
| 湿度与露点 | 环境测点与局部区域，选中后查看关联读数 | 不给每个部件编造湿度；稀疏测点不直接冒充精确体积场 |
| 气流 | 有方向的流线与粒子，必要时叠加温度切片 | 先核对送回风、柜体前后及通道关系；示意模型不宣称 CFD 结果 |
| 电力 | 设备负载着色、柜侧刻度、选中对象的明确供电路径 | 区分 W 与 Wh、实测与预算；路径动画须有已定义端点 |
| 容量 | 空闲 U 位立体槽块、局部透视、安装范围与尺寸 | 占用、预留、不可用分别表达；连续空间依据真实 U 位配置计算 |
| 告警与事件 | 局部轮廓、定位线和短暂脉冲，点击进入事件 | 避免全场持续闪烁；发生、恢复、影响对象和推断关系分开 |

一个主着色图层可搭配少量辅助流线与所选对象定位标记，避免多个色场竞争。动效要表达方向、过程或注意力；减少动态效果偏好与低画质路径仍能读懂数据。雾效、泛光和粒子不能遮住模型、文字与选择反馈。

### 趋势与时间联动

对象小趋势跟随当前图层；展开后查看完整曲线、对比指标与事件。拖动时间时，三维读数、热图、气流模型状态、汇总和告警同步；相机与结构展开姿态保持当前操作。粒子位置是视觉动画，业务值由统一时间快照决定，不依赖上一帧积分才能回看。

当前为 120 秒确定性演示。新增环境输入须记录位置、单位、来源、质量、模型假设及时间响应；未来历史数据接入另行设计。回放、场景巡游和镜头环绕分别控制，不能把环绕动画当作指标变化。

### 开发顺序与验收

| 顺序 | 交付 | 验收重点 |
| --- | --- | --- |
| 1. 场景与工作区精修（当前优先） | 气流可读性、四个关键画面、模型质感、导航与控件组合 | 完成上表交互与截图验收；数据能就地读懂，减少重复面板；既有链路无回退 |
| 2. 样板机房系统补全 | 按设施范围逐项明确空间、冷却、供电、布线与数据端点；打磨已有设备内部 | 模型、安装与关系一致；设施位置合理；没有数据的对象不伪装成监测对象 |
| 3. 容量与环境扩展 | U 位占用/预留/不可用、连续可用空间；具备测点定义后的湿度/露点 | 从安装配置计算；稀疏测点有边界；当前视图自然承载数据，再复核入口命名 |
| 4. 单建筑与单园区 | 建筑—楼层—机房，辅助区域与室外系统；复用样板契约扩展配置 | 稳定 ID、坐标转换、跨层定位、范围汇总与往返状态一致；按层加载通过验证 |
| 5. 多园区与地球入口 | 地球上展示已配置园区，逐级进入同一工作区；性能、资产压缩与作品展示 | 地理资源合规；宏观不加载全部细模；汇总不重复计量；记录真实设备上的性能与限制 |

领域资料仅用于核对监测对象与物理含义：[ASHRAE 数据中心章节](https://handbook.ashrae.org/Handbooks/A23/SI/A23_Ch20/a23_ch20_si.aspx)、[Vertiv 环境监测](https://www.vertiv.com/en-emea/products/trusted-names/geist/vertiv-geist-environmental-monitoring/)。页面布局、视觉语言与场景资产独立设计；实际环境阈值须结合设备要求，不直接套用演示规则。

## 领域设计原则

| 信息 | 基本约束 |
| --- | --- |
| 空间 | 明确坐标、单位、父级与稳定 ID |
| 资产 | 型号定义、安装实例与实际部件分开；槽位显式映射到模型节点 |
| 关系 | 网络、供电、冷却与成员关系分别建模，端点明确；不硬塞进单一空间树 |
| 状态 | 指标附单位、来源、观测时间与质量；健康、通信与告警分别记录 |
| 时间 | 所有视图共享时钟；模拟、实时与历史回放模式明确 |

设备既有机柜位置，也可有超节点成员身份；CDU 可关联多个机柜。关联不依赖显示名、数组顺序或猜测槽位，未知映射保持未知。

渲染层读取领域状态，模型通过映射关联业务 ID；选择、告警、搜索与拓扑共用对象标识。镜头动画不修改业务状态。模型姿态、部件配置信息和可逆爆炸编排按 [资产流程](../assets/README.md) 维护。

指标、告警与回放消费同一模拟状态，不让面板各自随机。相同输入和模拟时间得到一致结果；测量、模拟、派生汇总与推断明确标记。后续多源采集需定义更新、迟到和过期数据的合并规则。

功耗按设备、机柜和设施的计量边界汇总，标记覆盖率，区分转换损耗、未计量与缺失。零值有效，缺失、过期和离线分别表达。告警有稳定身份、严重度、对象及发生/恢复时间，考虑持续和恢复条件。相关异常不直接称为已证实根因。

## 渲染与技术选择

远景使用点位和简化几何，进入对应层级再加载细节。重复设备复用模型与材质，退出和取消加载时释放资源或使用有界缓存。示意与精确模型区分展示。

先验证桌面浏览器体验，再确定设备规模、画质与其他端适配。性能结果附设备、浏览器、对象规模、采样方法和限制；有原型后再制定可测预算。

原型采用 React + TypeScript + Vite，Three.js 负责参数化场景、射线选择与镜头控制。领域对象与层级状态、渲染对象和模拟时钟分离，使用稳定 ID 映射；重复静态几何按材质合并，远景按机型使用实例化外观简模，当前查看设备切换对应详细结构，缓存上限为已定义的四种配置。场景定义与经维护者授权的原创贡献模型作为资产登记；GLB 部件通过显式节点契约关联 ID，加载失败有简化结构提示。使用局部面光源、细节接触阴影和低对比程序化表面纹理增强材质层次，保持标准渲染降级路径；阴影及后处理资源随引擎释放。渲染与交互代码为 Apache-2.0。地图方案、服务端与持久化尚未确定。

温度切片、代表气流、指标标尺、网络/供电标记、通道范围和告警符号显式登记为数据图形，在接触阴影计算中整组排除，避免把切面当成实体板、把关系线当成实体管线。正常颜色绘制、深度遮挡、拾取规则及显示条件保持原定义；具有相同透明材质的实体不据此排除。

细节阴影的法线与深度计算排除文字精灵，避免 U 位短标、机柜名称等透明文字矩形被误当作实体遮蔽物而留下暗块。文字仍由正常画面通道绘制，保留各自的深度遮挡规则；不关闭整场接触阴影，也不改变模型材质、选择或指标口径。绘制结束及异常退出均恢复原可见性，原本隐藏的标注保持隐藏；标准画质沿用直接渲染。桌面验证覆盖前后视、设备抽出、回看与细节阴影切换，仍未代表跨浏览器或性能基准验收。

详细模型按四种设备机型和两类设施分别记录加载状态。制冷单元与配电柜随场景加载；机房预览和机柜安装图沿用简模，进入设备结构检视才请求对应机型，巡游也遵循同一规则。未查看机型显示“按需加载”，不当作加载失败；在途请求复用，已成功模型在当前场景内缓存，最多四种设备配置。离开设备后允许已有请求完成并缓存，不切回旧对象或移动镜头。加载期间可使用简化结构完成选择、展开与返回，结构就绪不再等待无关资源；场景重建也先使用当前机型的简化结构。模型请求或解析失败时保留简化结构，可从资源提示只重试失败项，不自动反复请求。加载成功和重试均保留当前选择、镜头、结构、图层与共享时间，交换机、存储展开后仍为配置示意。模型请求有 30 秒取消期限，销毁场景时取消在途请求并丢弃迟到结果。模型状态不代表设备离线、数据缺失或告警。桌面验收覆盖 1440×900、1024×768 的按需请求、慢加载导航、跨机型迟到结果、缓存、失败重试、结构与时间分析；模型大小尚未压缩，未代表性能基准或所有浏览器验收。

## 阶段状态与推进规则

机房到部件、统一工作区和环境回放的基础链路已经实现；气流可读性、整体视觉与模块组合尚需精修。当前优先执行上文“场景与工作区精修”，容量暂排在其后；单园区与地球入口仍为计划。阶段交付与验收集中维护在“开发顺序与验收”，避免多套路线互相冲突。

每完成一项明确任务，更新当前状态与限制，提供对应页面证据并本地提交。扩大规模前验证配置可复用与资源生命周期；性能结果须附设备、浏览器、对象规模、方法与限制。真实数据接入、公开部署与发布另按实际授权推进。
