## 项目介绍

浮城（Mirage）是一个面向数据中心的三维数字孪生个人项目。它规划以地球上的园区分布为入口，从园区、建筑与机房逐层深入机柜、设备和内部部件，将宏观的空间布局与微观的设备结构连接起来，构建一个可以浏览、探索和交互的数字世界。

项目规划通过机柜开合、设备抽出、结构拆解与爆炸图呈现设备形态，并结合网络、供电及冷却关系，关联功耗、温度、健康状态和告警等运行数据。借助空间定位与历史回放，让设备在哪里、如何连接、正在发生什么，都能在同一个场景中被观察和理解。

> 当前已实现本地的机房 → 机柜 → 设备 → 部件链路，包含双排八机柜、84 台混合设备、16 个后置 PDU 及演示供电端点。四种机型有独立的维护部件清单、可逆展开、选择与聚焦；温度、功耗、告警和态势共用一个可回放的确定性场景。宏观地图、完整关系网络与真机接入仍为建设目标，未部署在线演示。

## 探索路径

**地球 / 园区分布 → 园区 → 建筑 → 楼层 → 机房 → 机柜 → 设备 → 部件**

空间浏览、设备结构、网络/供电/冷却关系与运行数据相互关联。超节点作为可选的设备成员关系与专题视图，成员保留各自的物理位置。

第一版先贯通：**一个机房、八个混合机柜、四种设备配置、一个可重复播放的告警场景**。模拟数据明确标记，所有视图共享对象标识与时间线。先精修这套样板的场景表达、布局与设施关系，再扩展单园区，最后建设多园区与地球入口。详细边界与交付步骤见 [项目设计与路线](docs/project.md)。

## 模型与素材

以自主建模和参数化搭建为主，必要外部素材只选来源可靠、可明确核实的 CC0。没有合适素材就自行制作简化版本，保持统一尺寸、材质和结构，不堆放不同来源的模型或重复许可文件。

获准公开的模型、贴图、场景、预览和源文件统一放在 `assets/public/`；来源与许可集中记录在 [资产清单](assets/manifest.json)。原创场景与经维护者授权的原创贡献模型均已登记；未引入 CC0 以外的第三方素材库资源。制作、导出和登记方式见 [资产说明](assets/README.md)。

## 当前运行与检查

原型使用 React、TypeScript、Vite 与 Three.js。建议 Node.js 24，最低 22.12；首次安装依赖后启动本地开发服务：

```bash
npm install
npm run dev
```

打开终端显示的本地地址，即可进入统一三维工作区。主入口为“总览 / 温度 / 气流 / 功耗 / 告警”，对象操作和时间分析共用同一场景；默认从第 60 秒开始播放并自动巡游。顶部“演示”菜单可暂停或继续巡游，操作场景、查找资源或切换图层会接管为自由探索；模拟播放与巡游分别控制。减少动态效果偏好下默认自由探索，后台暂停画面、巡游与数据推进。

机房资源栏的“布置图”按配置位置显示八柜、制冷单元、配电柜与入口，也可切换“环境与安全”查找七处既有设施和检漏配置路径。设施可预览、定位、查看详情与分析，再返回原点位和查找。可按设备编号查找所属柜，预览联动三维选择，明确定位或进入；“俯看三维布置”与图上方向一致。深入设备或部件后，可安全返回原布置，保留查找与最新时间，恢复原视图和柜位焦点。图中空白不代表通行净距或可用容量。

温度视图切换“垂直切片”后，可“观察整排切片”，连续换排、调距离、预览逐柜输入并回看时间；返回恢复观察前镜头。切面插值与整柜有效输入分开解释，仍为同向双排样板的模拟表达。

暂停模拟且镜头、机构和选择动效结束后，场景帧循环休止；操作、模型到达和窗口恢复会唤醒更新。正常动效下，播放与镜头环绕仍连续更新。

场景标签随投影、控件和尺寸变化更新避让，静止时不重复布局。场景标签按任务收敛：总览只标所选对象，设备展开后随部件选择显示名称；“显示 → 更多对象标签”可补充浏览标记。选择用青白短角标；异常符号只在告警视图出现，总览、温度和功耗不叠状态符号或状态图例，设备内部不自动散布评估点。模型自带的铭牌和端口标识保留。对象详情先呈现状态、指标和小趋势，网络、供电与冷却关系以数量摘要按需展开；主动追踪对端时自动展开对应网络接入，完整配置与数据边界仍可查阅。

机房资源栏的“进风对照”可并列查看八柜按 U 位排列的整机进风分布、最高有效值和覆盖率。逐台名单可在当前柜与整间机房之间切换，按安装位置或有效进风从高到低排列，筛选有效进风或无当前值；跨柜查找后可继续双设备对照及结构检视，返回保留范围、排序与筛选。所选设备还可直接进入“机房气流”，连续核对分段、端点和输入历史，检视后安全返回原进风查找。选择设备联动三维安装位置，可进入安装位、内部结构或时间分析，再安全返回原对照；查找与回看不改变安装配置。颜色只表示有效模拟进风，无当前读数的设备使用斜线并说明原因。固定一台设备为基准后，可选择另一台打开“对照分析”，用共同刻度和共享游标比较两台整机进风，并同框观察两台设备的柜前安装跨度；可返回观察前视角，或沿两端检视后返回原对照。曲线下的“温差过程核对”可回看已发生的有效差值极值、数据失效边界，并返回核对前时刻；无效记录不补零，极值不代表异常或冷却效果。

温度与气流共用场景、选择、结构与模拟时钟。切换视图保留镜头和机构姿态；设备内部明确“查看该设备机房气流”才安全归位。气流目标由所查设备、机柜或格栅排决定，不再由温度切片柜排决定；可选叠片有独立参数，离开气流后默认收起。

温度图例常驻方向、位置与有效覆盖；展开覆盖可预览最高输入和未参与估计的设备，预览后返回按钮常驻。气流已独立为同级视图，场景内直接提供分段观察、端点返回、输入对照和可选切片；完整端点与布置边界放在右侧详情。温度的设备与环境工具从“观察与核对”展开，其中“对照所查设备 → 核对估计依据”可查看当前柜前位置采用的进风输入、计算占比及留白原因。三维同步标记估计位置与输入，可“观察估计位置”近看柜前标记并返回原视角，也支持预览输入详情后返回原设备对照；占比只解释现有插值，不代表热贡献、风量或测量置信度。

气流说明及分段近景可“对照输入与进风”，在右侧比较当前可见支路的演示冷却输入与整机进风，共用游标和模拟时间。回看、重播保留支路与观察段；返回恢复原详情或分析及导航状态，保留最新时间。无效进风留空，公共输入事件不随设备离线或过期消失；曲线不代表风量、排风温度或故障根因。“输入阶段核对”按已发生的输入事件列出首末读数和有效覆盖，可回看阶段两端并返回核对前时刻；首末变化不代表响应时延或冷却效果。

格栅排详情的“对应柜排”可逐柜查看既定代表设备、U 位及最近格栅落点，直接进入该支路的气流视图。从端点、安装位或设备内部检视后，可安全返回原格栅布置，恢复查找、切片和列表焦点；代表设备按配置高度选取，不按温度排名，也不表示独占供风范围。

机柜“空间核查”可从核查结果近看前后侧安装范围，并返回观察前镜头；切换观察侧、开门与回看不改变安装定义。“逐段观察”按高 U 到低 U 核对范围内的设备与连续盲板，括线只对应当前交集，可回到整个范围或检视本段设备。也可从范围占用名单预览整机，区分设备完整跨度与实际相交 U 位。继续进入安装位、内部或单部件后，可安全返回原范围，恢复核查输入、查找与列表焦点，保留最新回看时间；未安装位置仍不代表可分配容量。

机房总览选中机柜后，可分别观察柜前操作、柜后检修及排间预留范围。三种近景支持连续切换、对柜预览、时间分析及原视角返回；地面范围与右侧尺寸均来自配置，不代表实测净距或通行结论。

机房资源栏的“网络接入”可对照八柜的 A/B 逻辑接入，也可切换“全机房连接”，按机柜、设备、交换机对端或端口名称组合查找并筛选 A/B 分支；多个词须匹配同一条配置连接。点击端口标记三维两端，可同框观察安装位置并返回原视角，再从详情继续检视安装位、网卡或控制器；返回接入图保留范围、分支、机柜、查找、原连接、滚动与操作焦点；中等窗口可直接从详情返回。图中只包含已登记的柜内配置，不代表实时链路状态或实际布线。交换机详情提供全部 54 个逻辑端口的总览核对，支持编号/对端查找、键盘选择、已配置两端标记和未配置说明；检视端口所属部件后可安全返回原交换机与端口。

两处烟感详情可“逐点核对烟感布置”：预览保持镜头，近看从下方检查各自安装位，并核对配置坐标、高度及中心间距。可在分析中回看共享时间，再返回起点烟感，恢复原查找；从设备内部进入会先安全归位。烟感仍未接入数据，不表示探测覆盖或消防联动。

入口门或门禁读卡器的总览详情提供“核对入口布置”，可连续近看入口全貌、洞口尺寸及读卡器与把手位置。三维轮廓和高度参考线沿用现有配置，预览两端、分析回看或调整窗口后可返回原视角；门扇保持静态姿态，没有门锁控制或通行校核含义。

机房总览选中漏水控制器或感应线后，可从“核对检漏路径”连续观察完整布置、控制器与引线、感应线路径和末端封接。三维强调当前段与配置端点，右侧解释段长、坐标和布置边界；预览相关设施或回看后可返回原视角。仍为未接入信号的静态布置，不表示探测覆盖或泄漏事件。

环境测点详情中的“测点对照 → 对照两测点历史”可比较两处探头的温度、湿度与推导露点，共用曲线刻度和时间游标。两端身份固定，支持预览、定位与返回起点；“同框观察两测点”可一起查看墙面点位和各自高度参考，回看保留镜头，并可返回观察前视角。不同步或无效采样不计算差值，三维标记只代表固定点位，配置间距不表示监测覆盖或区域梯度。双点分析还可展开“可比过程”，回看已发生区间的首末秒并返回核对前时刻，分别解释两侧质量与采样同步条件。

时间控制位于页头：播放/暂停按钮控制模拟，“分析”打开所选对象的完整曲线、共享时间与已发生事件，替换右侧普通详情。点击或横向拖动曲线、选择事件或使用方向键回看，镜头与开盖、展开姿态保持不变；分析栏顶部可返回详情。暂停并待镜头、机构与选择动效停止后，场景停止重复绘制；旋转、回看或恢复播放会刷新画面，镜头环绕仍独立控制。机房、机柜与设施的事件按来源收起；展开一台设备，可按顺序回看告警变化，也可定位到它的机柜和 U 位。告警复用左侧资源筛选和场景标记，进入机柜后只查看该柜资源，不设置常驻底部告警表或时间条。场景与数据边界在“演示 → 场景与数据说明”中查看。

时间分析可“固定当前时刻对照”，再回看另一秒或悬停游标，直接比较两端温度、功耗及有效覆盖，并返回基准时刻。过期与缺失不补零，回看保留镜头和结构；更换对象、关闭分析或重播清除基准。

机房、机柜和制冷范围的最高进风曲线可展开“最高进风来源过程”，区分来源切换与有效覆盖变化，回看区间首末秒。预览来源后可继续查看机房气流、安装位和内部部件，再安全返回原范围分析，恢复核对基准、图层、切片和查找，保留最新共享时间。检视固定进入时的设备与依据，当前最高已切换时明确提示；并列来源全部保留，不把汇总曲线当作单台设备响应或故障根因。

机房、机柜、制冷单元、配电柜与 PDU 的“输入核对”可逐台查看汇总依据。预览后可沿气流或 A/B 供电关系进入设备与部件，再安全返回原名单；进入时的计入原因与当前状态分开说明，回看保留最新时间。返回恢复指标、分组、查找及列表位置，有效零值仍计入，过期与缺失不按零值处理。功耗输入的“预算口径过程”可核对计入条件变化前后的功耗、对应预算与占比，并返回核对前时刻；普通负载波动不另造口径事件。

时间分析先呈现当前对象的指标曲线和回放控制，再展示判定、来源与事件；主动回看告警仍直接定位判定说明。设备时间分析中的“持续条件过程”可核对温度预警、升级、降级与恢复的起点、等待秒数和确认时刻。支持逐秒回看并返回核对前时刻；回看保留镜头和结构姿态，部件沿用整机判定，过期历史与当前计时分开。

机房告警列表可按级别、设备与柜位逐台排查。选中一行即可对照三维安装位置和设备告警依据，从详情进入安装位、设备内部或告警过程，再安全归位返回列表并保留最新共享时间。返回时区分当前活动告警、无活动告警与不可判定的数据质量；不新增告警来源或确认/消除操作。

“演示”菜单可载入机房浏览、设备内部、告警排查和时间分析四个固定画面，载入时重置对象、时间、结构与切片设置并停止巡游。项目只保留一个正式工作区入口；旧评审、设计与原型链接不再触发特殊模式。后续页面调整遵循 [界面开发基线](docs/project.md#界面开发基线已确认)，功能范围与后续计划见 [工作区体验设计](docs/project.md#下一轮体验设计设计评审中)。

拖动旋转、滚轮缩放、单击选择、双击进入；面包屑与 Esc 返回，F 聚焦。机柜前后门可分别展示开合；前门与服务器导轨按顺序开合、抽出和归位；固定安装的交换机不使用抽屉动作，进入时切换到结构展示台。1U/2U 服务器可单独打开上盖观察装配内部，再展开或复原部件；合上上盖会先复原部件，返回机柜前自动合盖。手动开盖后“复原部件”保留开盖状态，图层和时间切换也保留结构姿态。设备支持独立部件选择。进入“只看此部件”后，右侧可逐项查看同级模块或子件、返回所属模块，再返回完整结构；切换自动聚焦，保留展开比例与共享时间。顺序沿用当前机型配置，不代表拆装步骤。资源栏标题右侧可收起导航，从场景工具栏左端“资源”重新展开；搜索条件保留，窄屏按 Esc 关闭导航后焦点返回入口。左侧按柜排与设施分组，行右侧提供定位与进入，不再使用底部选中卡片；机柜内部保留 U 位，设备内部按实际机型显示模块与子件，支持搜索；小屏仍通过资源导航选择。自动建筑剖切、细节阴影与镜头环绕集中在“显示”。需要支持 WebGL 2 的桌面浏览器，小屏上下浏览场景与详情。

4U 存储进入设备后，可从整机、前置硬盘组或硬盘详情“核对 24 个盘位”。正面四列六层盘位图与三维子件逐位对应，支持鼠标与方向键选择、单盘检视、分析回看和返回原盘位；结束后恢复完整结构，保留展开比例与最新时间。编号与读数仍属于内部配置示意，不代表真实盘槽、空槽或磁盘健康。

14×12 米机房有六个计算柜与两个计算/存储混合柜；交换机位于 U39 和 U41，4U 存储位于后排两柜的 U25–28 与 U35–38，PDU 装在后侧通道，不占标准 U 位。另有门禁读卡器、两处烟感、两处墙柱环境探头，以及制冷单元旁的漏水检测控制器和感应线，可从“环境与安全”资源组查找、选择与定位，详情显示配置位置、高度和数据边界；均未接入真实数据；两处环境探头已定义独立的温湿度演示采样，可从温度视图进入点位、回看同一时钟下的温湿度与推导露点，数据边界见[项目说明](docs/project.md#样板机房与园区设施范围待实施)。其他安全设施仍无读数；不生成设施告警。两段既有桥架可从“建筑与布线”查找和定位，按需查看端点及下方机柜的空间对应；均为静态布置，没有运行数据或已接通线缆的含义。桥架与顶灯的六处交叉支持从关系详情同框核对配置表面高差、预览两端并返回原视角；机房总览还可从桥架或机柜关系进入“核对柜顶高差”，同框查看实际横档底面与柜顶板表面，连续预览、回看后返回原镜头。两类高差均不是工程净距或安全结论。所有设备安装范围均做冲突检查；前置 1U 盲板按每柜实际安装 U 位独立生成，未安装位置连续封闭，数量与范围可在机柜“配置与数据说明”中查看。盲板不表示可分配容量。配置集中在 `assets/public/scenes/room-01.json`：

维护部件还包括上盖、处理器封装与散热器、托架与磁盘背板、导风罩、时钟电池、管理接口和线束。清单内的每一项都对应可选择几何；2U 计算设备有 21 个模块、36 个子件。GPU 等选配件在当前配置中明确未安装，不生成虚假槽位或遥测。1U/2U 计算设备保留已获准的贡献结构，并适配当前配置及原创补充部件；交换机与 4U 存储已接入保留贴图的贡献外观模型；展开时切换到独立制作的内部配置示意，复原后恢复外观。贡献资产不包含完整内部结构，示意配置不冒充其精确 CAD。通用配置不是某款厂商设备的精确 CAD 或维修手册。

总览显示原始材质、选择标记与运行概览；开盖、展开和复原属于对象操作，在所有图层中可用。机房温度视图直接显示进风温度切片，可在图例中切换水平/垂直方向：水平调高度，垂直选 A/B 排并调离柜距离；标签分别显示“本层约”或“切面最高约”，U 位色条保留逐台设备读数。切换方向、位置或回看不改变对象和结构姿态。空白表示无有效估计，切片不代表整间机房环境温度。气流场景默认显示一条送风、穿柜与回风代表支路，路径随所查设备、机柜或格栅排变化；送风逻辑端点、柜前格栅、设备进风和回风假设就地标注，当前支路对应的齐平格栅以细轮廓标出，完整端点与边界可从右侧详情查阅；冷却输入与粒子共用模拟时钟，暂停及回看保持确定结果。气流视图可分段观察送风、设备进风和柜后回风，强调当前段，默认不显示切片；可主动叠加切片并返回原视角。路径颜色区分环节，送风线明暗表示冷却输入，均不代表实测风速或排风温度；停机或无效观测对象只保留静态示意。功耗通过预算标尺显示，设备内部保留部件表面着色。右侧只展示所选对象概览，温度取有效设备最高进风值，功耗仅汇总有效观测，分别报告覆盖率。运行、维护、停机、离线与数据质量独立记录；过期值停在最后观测，不进入当前合计，停机零功耗有效。部件温度与功耗是模型推导，不能充当独立测点或告警。

制冷单元详情可按配置查看 8 柜、84 台设备的关联范围、最高有效进风、覆盖率与设备告警；可逐柜展开，按机柜、设备或机型查找，并筛选无当前进风或当前告警设备。预览、气流与内部结构检视后，可安全返回服务范围并恢复查找、展开项和滚动位置，保留最新共享时间。从机柜、设备或部件查看机房气流时，可沿所属柜排继续观察同一支路，展开或抽出的设备先归位。时间分析对照演示冷却输入（0–100%）和关联设备最高进风，共享回看与事件；恢复输入后仍可观察温度的滞后响应。输入百分比不是风量、制冷量或设施功率，关联进风不是制冷单元送/回风测点，关联事件也不等于已证实根因。过期、离线、缺失与停机无进风值分别说明，不进入当前最高值；部件沿用所属设备关系。

功耗视图追踪一条已配置输入后，可从详情或图例“同框观察插座与输入”。柜后近景只强调 PDU 插座至设备输入，按需剖切目标柜后侧；支持 A/B 切换、回看及返回原视角。从电源部件返回安装位先安全归位，再继续观察。未连接位置没有对端，图中仍不表示支路计量或实际施工布线。

每台计算/存储设备有显式网络 A/B 接入关系，各接本柜一台交换机，共 136 条 25G 配置接入。总览对象详情支持逐柜查看接入交换机、按逻辑端口查找对端、显示未配置端口与端点标记；交换机登记 48 个 25G、6 个 100G 逻辑口，100G 尚未配置上联。服务器映射到网卡，存储按两控制器各一条接入，另外两口保持未配置；展开后的标记跟随所属部件。场景以空心端点和简短编号标记当前一条关系的设备代表位置或内部部件；右侧集中展示两端端口、位置和所属部件，可直接预览或定位，切换视图与回看保留关系。标记不是物理端口定位或施工线缆。链路状态、协商速率与流量未采集；未配置不等于空闲，设备离线不等于断链，A/B 不证明上联独立或冗余保障。没有虚构上联骨干或真实拓扑。

机房功耗视图的资源栏可打开“功耗对照”：八柜卡片并列显示有效输入、覆盖数及对应预算占比，支持本柜或全机房查找，可按安装位置、功耗或预算占比排列，区分有效输入、未计入输入和有效零值。可进入安装位、设备内部、供电端点或时间分析，再安全返回原对照，保留查找、数据分组和最新共享时间。卡片与三维标尺共用汇总口径，筛选不改变柜级总数；没有新增设施或支路计量。

时间分析的功耗曲线可“对照有效设备预算”：实线输入与虚线预算共用刻度和游标，同时核对占比及覆盖变化。回看保留镜头与结构，缺失或过期断线，停机有效零值保留预算；部件推导不参与，曲线差距不表示容量余量。

功耗图例与对象详情可打开“功耗预算”核对：同时显示有效输入、对应设备预算分母、全部配置预算与未计入设备预算。名单逐台列出配置预算和当前占比，可预览设备后返回原筛选；回看同步更新覆盖，停机零值保留预算，过期旧值不计入。占比只比较同一批有效设备，不表示额定容量、设施计量或可分配余量。

供电演示已定义配电柜的 16 个逻辑出线、16 个后置 24 插座 PDU 与 84 台设备的 168 个电源输入。功耗场景显示当前对象的代表配置支路，A 实线、B 分段，均为静态配线示意；右侧供电连接可追到已接/未连接插座和设备电源，并从已接插座或设备输入追踪单条配置支路；场景框选对应插座。PDU 详情按配置高度逐位核对 24 个插座，查找保留完整排布；可检视对端电源并安全返回原插座，未连接位置只做框标。切换视图收起标记，返回功耗或回看可继续。PDU 可搜索并定位到所属机柜后视，功耗或 PDU 观察会剖切后立柱及关闭的后门，手动打开的双扇门保留可见，离开观察后恢复完整柜体；不是门板拆卸或实际控制。设备电源标签跟随部件展开，交换机与存储仍为内部配置示意。设施详情与时间分析只展示去重后的关联整机输入，保持有效覆盖，离线、过期、缺失与有效零值分开。配电柜、回路、PDU 和插座未计量，整机输入不拆分到 A/B，不据此声明独立上游或冗余保障。
