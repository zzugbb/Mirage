# 项目设计与路线

## 目标与当前状态

Mirage · 浮城是面向数据中心的三维数字孪生个人项目。目标是把现实基础设施的空间、结构、连接与运行变化组织为可探索的数字世界，同时积累三维图形、领域建模、模型流程、实时数据与性能工程经验。

面向希望理解机房及设备运行的体验者、开发者和运维人员。项目独立设计，不限定于某个厂商、某种设备或特定管理系统；服务器与超节点按各自结构处理。

当前已完成机房 → 机柜 → 设备 → 部件的本地浏览链路，含镜头控制、结构展开复原、自动巡游和共享时钟的温度、功耗、运行状态与告警。八机柜包含 1U/2U 计算、接入交换机和双控存储，交换机和 4U 存储已换用保留贴图的贡献外观，内部仍为独立配置示意；机型分别维护部件契约与可选配置；明确配置中的维护部件都有可选择几何。顶置交换机与后置 PDU 按安装约束布置，端口和 U 位做唯一性/冲突校验。趋势与时间控制按需打开，数据来源统一说明。运行方式、配置规模和限制集中见 [README](../README.md)。宏观入口、真实数据接入、完整网络拓扑及上游供电系统尚未实现。素材与许可集中见 [资产说明](../assets/README.md) 和 [许可范围](../LICENSE-ASSETS.md)。

## 体验范围

空间路径：**地球 / 园区分布 → 园区 → 建筑 → 楼层 → 机房 → 机柜 → 设备 → 部件**。

建设顺序由内向外：先精修一套完整机房，再形成单园区，最后扩展多园区与地球入口。地球展示已配置园区及可追溯汇总，不加载所有园区的设备细节；地域筛选属于分布入口，不作为必须经过的空间层级。

| 方向 | 目标 |
| --- | --- |
| 空间浏览 | 园区分布、建筑分层、机房布局、墙体门窗、通道、制冷与配电设施；逐层进入、返回、旋转、缩放与聚焦 |
| 结构探索 | 机柜前后视角与开合、U 位安装、设备抽出/开盖、部件高亮、爆炸展开与复原 |
| 关系查看 | 网络端口与链路、供电与冷却关联、超节点成员；与物理位置联动 |
| 运行状态 | 功耗、温度、健康状态、指标趋势、告警发生与恢复；搜索和告警可直接定位 |
| 时间回放 | 场景暂停、重置、回看及重复运行，三维、拓扑和图表时间一致 |

地球、地图、地形与园区坐标资源使用前核实来源、许可与适用要求，遵循现有资产规则。没有可用数据时使用明确标记的示意位置，不把虚构园区当作真实地点。

## 第一条完整链路

以当前机房为样板，精做建筑空间、机柜、四种已有设备及维护部件，再向一栋建筑和一个园区扩展。每个层级都要有完整的进入、操作、数据表达与返回体验。当前贯通的模拟场景继续作为设计验收主线：

**冷却能力变化 → 温度响应 → 告警触发 → 定位设备 → 查看趋势与关系 → 恢复回放。**

使用固定种子、有版本的场景与事件序列；其他对象用统一风格的原创简化资源。模拟规则和延迟明确记录，不宣称是精确热流体仿真或故障预测。超节点可作少量关系叠加或后续专题，不阻塞首条链路。

初期不连接实际管理系统，不执行远程开关机或配置变更。真实数据源从后续只读适配开始，单独记录验证范围。

## 下一轮体验设计（设计评审中）

本节记录已落地的统一工作区与后续设计基线。默认入口已整合资源定位、数据图层、对象操作、时间分析和自动巡游，只保留一个正式入口。后续环境能力继续按本节逐步实施，名称与布局通过实际画面打磨；不因新增指标继续增加同级页签，也不在页面预留尚不可用的入口。

### 界面开发基线（已确认）

当前场景工作台已确认作为正式开发基线，后续继续在这一套布局上完善，不重新设计一套界面。正式入口为总览、温度、气流、功耗、告警五个视图，共用默认工作区、场景、选择、结构和模拟时钟；继续完善样板机房完整度；容量、连接与园区尺度仍按后续阶段实施。

- 三维是主体；左侧定位资源，右侧解释所选对象。详情与完整分析互相替换，告警复用资源筛选及空间标记，不恢复常驻底部告警表、时间条与曲线的堆叠。
- 资源行统一为名称及就近状态、类型/位置、横向操作；按钮与名称对齐，普通、悬停、选中和禁用状态均可辨认。浏览时行宽留给编号与读数；悬停、键盘聚焦或选中时显示定位、进入等操作。
- 按桌面工作台设计，优先保证三维视口和鼠标、键盘操作。视图、视角与结构操作留在场景内，控件按可用宽度避让，中等窗口的资源与详情分时占位。
- 指标与状态分开表达，保留单位、范围、数据质量和模拟边界。设备与部件的当前读数和趋势共用有效值，停机零功耗显示为零。过期旧值和最后有效时刻可在“配置与数据说明”核对。场景放位置与读数，面板放比较与解释；说明按需展开，不堆重复数字、标题和装饰。
- 场景优先用视觉表达，少用文字覆盖设备。通过局部轮廓、端点、方向箭头、空间刻度与有含义的短促动效呈现选择、关系和变化，让模型与材质形成视觉中心。就地文字限于必要身份、单位与关键读数，随选择或明确查看动作出现；长说明和配置边界进入右侧详情或按需展开。炫酷感不能依赖遮挡设备的文字卡、泛光或密集粒子，也不能仅靠颜色和动画传递信息；暂停、减少动态效果及键盘操作时仍可理解和查阅。
- 时间分析围绕当前对象，入口、播放状态、场景同步与返回路径清楚；回看保留镜头与结构姿态。常规打开先显示指标曲线，再呈现判定、最高来源过程、输入依据与事件；显式核对入口仍可直接定位对应说明。新能力先融入现有模块，不以新增同级页签替代信息组织。
- 标签和关系清单按当前任务出现。普通点选先让人辨认对象；需要比较范围或尺寸时，由明确入口启动核对。验收要连续看点选、开始核对、打开分析和退出四个画面，检查地面标记出现的时机，以及曲线能否在首屏读到。“显示”初始关闭更多对象标签与自动建筑剖切，开启镜头环绕与细节阴影。减少动态效果时镜头保持静止；阴影依渲染能力启用。总览优先标识所选对象，补充标签仍按层级限量并避让；关闭更多标签后优先显示所选对象，机房告警视图在未选择具体对象时保留当前最高级别的提示。部件模型评估留在资源状态与详情。温度、功耗保留必要读数。设备温度与功耗短标沿用资源编号，用引线指回部件并避让相邻读数。检查交换机与存储的展开视图时，读数应让出整排端口和盘位，上盖应让出控制器与风扇。温度名单默认按进风降序。从温度、告警或功耗名单定位异常设备时，柜内按当前视图的判定勾出所选 U 位，编号避开设备面板。功耗占比随当前对象计算，部件超过预算时，正常整机仍按自身读数显示。进风告警和功耗预算状态分别强调各自的读数；进入设备后，告警图形随整机，单独检视部件时收起。气流与主动追踪端点优先，避免同一部件重复贴名；选中标签就近避让并以引线关联原位置，气流端点与设备身份共用标签空间。详情顺序固定为身份/异常 → 指标 → 小趋势 → 按需展开的关系与配置，不让长端口表将趋势挤出首屏。
- 先在两侧栏同时打开时检查首屏。当前图层由场景页签标识，资源栏直接给出搜索、名单与有效覆盖。筛选收起后仍显示已用条件；详情中可点击的覆盖数直接进入输入核对。预算或冷却的推导口径就近展开，告警级别、数据失效与返回操作始终可见。验证时实际点开、收起、切换对象并返回，尤其检查中等窗口切换侧栏后的入口与焦点。
- 常规界面验收以 1440×900 桌面视口为主，以 1024×768 中等窗口为辅。在实际页面核对涉及的机房、机柜、设备/部件及告警/分析组合，并保存关键交互截图。保留已有手机布局。手机专用布局、触控交互及 390px 截图不列入常规开发与验收范围。

普通资源列表用于查找对象。设施按位置从布置图进入，安装 U 位和排间通道归入空间核查，连接归入网络接入，配电出线归入功耗，制冷服务归入气流。端口、出线和安装位的详情操作承接当前对象。双栏同屏时收起通向已打开名单的快捷按钮。

任务入口、模块替换和返回的设计与验收遵循[布局与信息取舍](#布局与信息取舍)。

### 本轮设计收敛与待实施重点

本节保留场景表达与工作区的设计依据及已实现范围，现阶段验收结论见[阶段状态与推进规则](#阶段状态与推进规则)。

首批精修已落地：资源导航收起按钮位于栏内标题右侧，收起后从场景工具栏左端的“资源”入口展开；页头只保留空间路径。展开时聚焦搜索，关闭后焦点返回入口，窄屏支持 Esc 收起导航，搜索条件与对象选择保留；进入对象保留桌面导航选择；温度图例压缩至场景下沿，常驻切片方向、位置、有效覆盖与估计范围，中等窗口将水平切片方向与高度放在同一行，滑杆可直接拖动；最高输入预览并入覆盖说明，预览返回入口保持可见。温度的设备与环境工具在“观察与核对”内按需展开；气流视图直接提供分段观察与返回，端点和布置依据在右侧详情查阅；内层说明与工具入口分别响应 Escape，载入固定画面清空展开状态。气流使用具有实体宽度的送风线、分段回风线与更清晰的方向箭头，保留暂停、过期静态与真实遮挡。门禁读卡器、两处烟感、两处墙柱环境探头，以及漏水检测控制器和感应线已支持独立选择、查找和定位，其中环境探头的模拟观测见下文。气流端点标签与格栅配置已补齐（见下文）；建筑遮挡已增加自动剖切；建筑背景材质已收敛（见下文）；通道比例、设施关系及其余关键画面仍待精修。

机房温度的垂直切片提供“观察整排切片”：切面边界与所属四柜同框，连续切换 A/B 排及离柜距离时重新取景，温度视图不显示代表气流。柜旁短标为各柜切面最高估计，右侧分别列出切面估计范围、逐柜有效输入覆盖与整柜最高进风，可预览同排机柜而保持构图。取景点来自切片和安装位置，不随时间、读数质量或覆盖变化；后排从上方越过前排观察，自动建筑剖切检查切面内部视线，仍保留柜体深度遮挡。详情与时间分析共用说明；窗口和侧栏变化重新适配。返回按钮或观察操作区内 Esc 恢复首次观察前镜头与入口焦点，保留最新选择、切片参数和共享时间。手动镜头、标准视角、主动定位、无关对象、切换水平切片、离开温度/机房或固定演示画面结束观察；内部检视须先沿既有机构归位回到机房。该能力只核对当前同向双排的局部插值示意，不新增温场数据、风口或真实热工验证。

**规模先保持，完整度先提升。** 当前 14×12 米、8 柜、84 台设备作为样板与回归基线。暂不通过加柜、复制设备或扩大空地制造规模感；只有新增系统、合理通道或服务空间确实需要时才调整尺寸。扩展前先验证不同朝向、不同机房配置和对象 ID 的复用，避免把当前同向双排布置写死成通用机房。

**气流必须可辨认。** 当前已用就地标签标明端点，并收敛一条完整代表路径：制冷单元送出 → 地板送风位置 → 目标设备进风 → 柜后回风假设；用具有可见宽度的流带、间隔明确的方向标与短脉冲表达流向。送风与回风通过色彩、实虚和端点共同区分；暂停时仍能读出方向。只在端点附近给出“送风 / 进风 / 回风假设”和当前有效读数，选中后强调该支路，其余减弱。气流已拆为独立视图，默认显示代表路径而不显示温度切片；切片作为主动叠加选项，参数与温度视图分开保存。当前室内总览只显示一条代表支路；需要时选中其他机柜或设备切换，不同时铺开多条路径。不得用整场泛光、铺满粒子或关闭所有深度遮挡补救可见性，也不把线宽或运动速度解释成未定义的风量。

**场景承载位置与数值，面板承载比较与解释。** 温度放在切片、测点及对象附近；功耗放在柜侧标尺和已定义供电支路；容量放在空闲 U 位；告警放在异常对象和独立告警入口。关键数字必须有单位、对象和数据质量，精确值随选中显现；三维负责发现，曲线负责时间比较，列表负责检索。取消重复 KPI、长标题、常驻说明和重复操作；来源、模型边界与配置折叠查看。信息移入场景后仍要有键盘可访问的对象详情，不能只依赖悬停、颜色或动画。

**视觉目标是精致的基础设施作品。** 保留金属、PCB、线缆与建筑的材质层次，降低地板重复纹理、墙体和桥架对主体的争抢；根据视角处理遮挡，选中与展开对象形成清晰视觉中心。科技感来自可解释的流向、空间刻度、切片和时间变化。数据颜色与状态颜色保持独立，不让所有正常设备发光，也不以满屏标签增加信息感。

机房背景已降低地板重复细节、墙面与桥架的反光对比。地面保留 0.5 m 分格，以连续表面和低对比程序纹理替代逐块实体地砖；纹理随观察距离平滑过滤，避免远景接缝形成细碎噪点。地面顶高、格栅、通道、设施位置与照明强度沿用原配置；墙体、框架和吊装结构分别配置颜色、金属度与粗糙度。地面分格属于外观表达，不表示已建模可拆地板、架空送风层或真实材质参数；标准渲染和细节阴影共用同一表面定义。

空间标记按视图区分含义：总览只看原始模型、结构与选择；温度表达设备进风、部件温度与环境测点；气流表达代表路径和端点读数；功耗只表达负载与供电配置；告警只呈现实际设备告警。青白短角标表示选择，切换选择或主动聚焦时只做一次短促收拢，回看不重播，减少动态效果时立即静止。告警以局部三角/菱形区分预警/严重，不再同时叠整柜染色和多张状态文字卡；其他视图不铺状态符号或状态图例。标记保留深度遮挡，身份、数据质量与当前状态仍可从资源及所选对象详情查阅；设备内部不自动散布模型评估点或线框。机柜通道标签只保留方向和尺寸，预留边界在图例集中说明。

机房可按需开启自动建筑剖切：以相机到机柜中部与顶部代表点的视线，检查两面墙、两段桥架和三条吊灯的包围盒，整段剖切挡路的背景结构，移开视角后恢复；边缘保留少量退出余量以减少反复闪现。墙上门禁和环境探头随所在墙剖切；选择设施时改用设施位置判断遮挡，并保留其安装墙面，地板、机柜、设备、气流及照明强度保持原有定义。取消“显示 → 自动建筑剖切”可恢复完整建筑；机柜及设备层级禁用此选项，返回机房保留偏好。它是当前静态样板的观察辅助，不是逐像素遮挡判断或真实建筑改动；通道尺寸与完整建筑设施校准仍未完成。本轮已在本机 Chromium 检查桌面、窄屏的开关、旋转、层级往返及气流/设备/告警/分析组合，无新增数据或监测能力。

机柜后部由实心板改为带接缝、边框、把手与铰链的双扇冲孔后门，沿用功耗/PDU 观察剖切；前后门操作分别明确标为“打开前门 / 关闭前门”和“打开后门 / 关闭后门”。顶部两个刷条进线口由实体板块围出开口，保留 U42 顶部空间；后置 PDU 向柜内校准，避开侧板，并以三处支架连接侧壁，插座与供电标记沿用同一位置配置。八柜共用这些结构，不新增设备身份、测点或告警。尺寸与材质是布置示意，冲孔不声明工程开孔率或散热能力，进线口未定义施工线缆或桥架接入；完整布线仍待校核。

双扇后门沿各自外侧铰轴向柜后对开，展示角度 105°、时长 0.7 秒集中配置；闭合外廓与既有门网、把手保持一致。机柜内可独立操作前后门，回看和图层切换保留后门姿态，减少动态效果时直接到终态。功耗或 PDU 观察仍剖切后立柱；手动打开时保留门板，关闭后恢复原后侧观察剖切，离开该观察恢复完整柜体，并保留手动门板姿态。同柜预览和 PDU 定位不复原后门，跨柜及设施定位先合拢旧柜后门，再切换安装实例；进入设备展示台、返回机房和载入预设时归位，不让其他柜继承姿态。几何检查覆盖八柜开合全行程与柜后预留、PDU 和后立柱的关系，仍不表示实际作业净距或工程安全校核。门板姿态只用于结构展示，没有门状态测点、告警或远程控制。桌面验收覆盖两种视口、前后门独立操作、PDU 剖切、回看、跨柜和设备往返，以及普通动画下等待归位。

四种机型的安装简模补齐后侧配置轮廓：1U/2U 服务器呈现双电源、接口区和通风格栅，交换机呈现双电源与四处通风模块，存储呈现双电源与两处后部通风区。尺寸与材质集中在场景配置；每种机型合并为三个材质批次并实例化，保留整机身份、U 位与原有图层口径，不因观察背面下载细模。进入设备仍按需加载；交换机或存储外观成功加载后替换对应安装简模，失败时保留简模，重试不叠画。机柜配置说明保留表达边界：接口矩形不是实际端口映射，格栅不代表真实开孔、风量或运行状态，未补施工线缆。桌面验收覆盖混合机柜后视、四机型预览、图层与回看、细模失败和重试返回。

4U 存储配置示意已校准盘组与中板的装配关系：24 个盘位沿用 4 列 × 6 层排列，与竖直中板的 24 个示意接点共用槽位中心，装配状态下接触面对齐；板面细节不再错误沿板顶排列。盘体补充两侧托架、前置拉手与后部接触面，保留各硬盘子件身份；两路后部电源及接口收回机箱深度内。展开仍由所属模组驱动，复原回到已登记的贡献外观；几何核对覆盖接点对齐、盘位互不穿插、独立拾取和后部空间边界。接点只说明装配对应，不定义真实连接器规格、中板电路或控制器内部连线，仍是配置示意，未增加独立测点、告警或维护控制。

M1 紧凑型 1U 服务器可从机房“总览 → 机房资源 → 列表”按机型或设备编号查找，从设备行查看所在机柜，在安装图核对 U 位后查看设备内部。设备、托架组、固态硬盘组及对应子件的“结构核对”共用四个前置盘位。从柜前看，面板左侧两列分别为上 01 / 下 02 和上 03 / 下 04。托架位置取自外观模型，同号 SSD 按机型配置示意；切换托架与硬盘保留盘位，可沿用单件检视和时间分析。从查找或筛选结果进柜后，顶部“返回机房名单”恢复原筛选、设备行和焦点，保留最新模拟时刻。

4U 存储的“核对 24 个盘位”从设备、前置硬盘组或硬盘详情的“结构核对”进入，沿既有机构展开内部配置；已经部分展开时保持原比例。二维盘位顺序复用三维子件清单和槽位中心，正面四列六层从上到下、从左到右排列。核对时只显示盘组，点击二维盘位或三维硬盘更新选择与详情，不改变盘组构图；方向键在相邻行列移动焦点，Home/End 到同行首末，Enter 选择。可单独检视硬盘、切换其他盘位、分析回看，再返回正面盘组并恢复原盘位焦点；窗口变化按完整可见盘组适配。结束核对返回完整展开结构，保留最新时间和展开比例，不强制复原外观或恢复旧镜头。操作区 Esc 从单盘/分析返回盘位，再结束核对；复原、无关部件、换实例、离开设备或固定画面结束核对，跨层级仍沿用机构安全归位。沿用现有 24 个已配置子件，不生成空槽、磁盘实测健康、热插拔控制或容量余量；编号不是贡献外观型号的真实槽位映射，单盘读数仍为模型推导。

盘位核对中选中硬盘后，可“核对中板接点”：只保留该硬盘与完整中板，侧上方取景同时容纳两者，用局部轮廓与静态虚线对应实际建模的硬盘后部接触面和中板接点。单盘和接点视图用盘位选择器换盘并同步对应位置，三维可选择中板而保留原盘位；沿用原展开比例，窗口变化适配两者范围。分析回看保留结构和镜头；返回盘位总览恢复正面盘组、原盘位选择与焦点，保留最新时间。操作区 Esc、结束核对、复原、无关部件和跨层级安全归位沿用盘位会话规则。接点轮廓保留深度遮挡，不参与实体接触阴影；虚线只说明装配对应，展开间隔不是线缆长度，没有新增电气连接、磁盘状态、拔插步骤或贡献外观型号的真实连接器映射。

M2 通用计算服务器的整机、处理器封装与散热器详情共用“结构核对 → 核对处理器与散热器”。每次只显示所选路的 CPU 封装与同号 HS 散热器，切换部件保留镜头，切换槽位保留所查的部件类型。装配时，配置示意封装的顶面与对应散热器底面居中贴合；散热器细节沿用已登记的模型节点。首次从装配态进入时展开到 55%，已展开时沿用原比例。可直接进行部件时间分析，从机房筛选结果进入的设备按原路径返回名单。温度和功耗沿用模型读数。

N1 接入交换机的设备、交换控制主板及交换芯片详情共用“结构核对 → 核对主板与交换芯片”。展开后可同时观察控制板（CTRL）和芯片散热组件（ASIC）。板上四角标出配置安装区，组件从下到上为封装基板、芯片封装、散热底座和鳍片。操作条或三维拾取可切换部件详情并保留当前构图；结构操作可调整展开比例，时间分析沿用部件模型读数。返回完整结构可继续核对风扇组，从查找结果进柜也可用顶部路径直接返回机房原行。外观沿用贡献模型，板形与装配位置为配置示意。控制板后缘避让后部两路电源和四个独立可选的风扇，几何检查覆盖接触面、净空及 1U 边界。

交换机四个、存储两个风扇的内部配置示意已由实心块替换为贯通框体、两端开口、静态叶轮、支撑和侧边拉取结构，保持原安装间距及模块尺寸。每个风扇沿用原子件身份，选择、展开、复原和指标口径不变；主动定位从后侧略俯视观察叶轮，预览不移动镜头，手选视角仍可覆盖。几何检查核对开口与叶间空隙、机箱边界、装配/展开后的两端拾取及定位视线；新增细节不生成资源、转速、风量或独立告警，叶型、材质和拉取结构不代表贡献外观模型的精确内部构造或热插拔工程校核。

四种机型在设备、风扇组或风扇子件详情的“结构核对”中提供“核对风扇组”。服务器与交换机沿用四个维护子件，存储沿用两个，计数不等于叶轮数量；名单保持配置顺序，不作为左右位置图或拆装步骤。核对时只显示整组，名单选择与三维拾取更新子件详情而保留组构图；前后侧沿设备坐标观察，不据此判断气流方向。方向键、Home/End 移动清单焦点，Enter 选择；可单独检视子件、切换子件或分析回看，再返回所选侧整组及原子件焦点。结束核对选择整机并适配完整展开范围，保留展开比例和最新时间；操作区 Esc 先从单件/分析返回组，再结束核对。复原、合盖、选择无关部件、换实例、离开设备或固定画面清除核对；跨层级仍先安全归位。中等窗口让出资源栏以保留核对操作，窗口变化按可见隔离范围适配。沿用已有资产及内部示意，未新增转速、风量、健康、冗余判断、独立测点、告警或热插拔控制。

设备详情的闲置结构核对入口统一收在小趋势之后，默认折叠，只列当前对象适用的风扇组、盘位或装配核查；状态、异常、指标及趋势先呈现。展开或收起工具不改变相机、结构或共享时间，工具区 Esc 收起并归还摘要焦点。开始核对后沿用原三维与操作区；明确结束核对（含分析中结束）返回普通详情和完整展开结构，自动展开“结构核对”并在场景就绪后恢复对应入口焦点，可继续另一项核对。普通分析不显示未开始的工具，返回详情后默认收起；切换对象、实例、层级或固定画面不携带旧工具展开与入口焦点，主动键盘或鼠标操作取消待恢复焦点。复原、合盖和无关对象清理仍沿用各核对规则，不自动重新开始。

七处环境与安全设施使用稳定 ID，安装位置、所属墙面和定位视角集中在场景配置。门禁读卡器移至入口左侧，避开配电柜遮挡；烟感定位可从下方观察，自动剖切避让所选设施。资源预览不移动镜头，定位保留查找条件，跨设备定位先完成结构归位；场景只显示所选名称与短角标，详细位置和配置高度进入右侧。未定义演示采样的设施不冒充离线设备，不纳入设备汇总或告警；其时间分析说明没有曲线和事件，但保留共享时间与返回详情路径。环境探头的演示采样见下文；仍没有探测覆盖、消防联动或门锁控制。漏水检测控制器位于左墙制冷单元旁，明确引线、接头、感应线路径与封端；配置感应段长 4.35 m，引线约 1.45 m，仅用于布置示意。详情按需查看控制器—感应线对应和邻近制冷单元，可分别预览与定位；几何检查核对路径连续、室内地面高度及与柜体、设施、检修预留范围不相交。线状设施按端点、转折与段中点检查建筑遮挡，避免窄屏仅避让接头而让桥架挡住远端，同时保留关联控制器的安装墙面；仍可恢复完整建筑。线缆没有动态或状态灯，不表示实际接线、探测覆盖、已发生泄漏或制冷故障；真实环境监测与消防联动仍待定义。

气流“对照输入与进风”的曲线下可展开“输入阶段核对”。阶段边界只取已发生的公共输入事件，当前段截止共享时间；两端并列显示演示输入百分比、整机进风和质量，并报告期间有效时刻数。首末变化仅在两端进风有效时计算，无效值不补零；过期端另列最后观测时刻。首次回看固定当时记录及返回时刻，连续核对首末秒保留气流观察段与镜头，三维读数和曲线跟随共享时钟；返回核对前时刻后继续跟随当前记录。Esc 收起并归还标题焦点，重播或结束支路对照清除基准。输入百分比不是风量或制冷量，阶段不由设备告警划分，首末变化不表示连续有效、响应时延或冷却效果。已在两种桌面尺寸、普通与减少动态效果下核对四机型、有效/过期/离线/未配置/停机、窗口变化与时刻返回。

**当前工作区（已接入确认的界面基线）**：右上“演示”提供机房浏览、设备内部、告警排查和时间分析四个固定画面，复用现有三维引擎、对象操作和第 60 秒暂停的模拟状态。资源行统一为名称、类型/位置、状态符号和横向操作区，状态紧随名称，定位与进入对齐名称行并保留轻边界，普通行以细分隔建立归属；悬停、键盘焦点和选中分别反馈，子件沿用相同选中样式。跨范围搜索保留机柜与 U 位，部件子件按需展开；搜索结果计数包含匹配子件，空结果区分筛选不匹配与当前范围无告警。单击名称预览，定位聚焦，进入下一级，三者保持明确区分。视图切换与视角工具位于场景上方，视角、聚焦与显示设置合为一组，按场景实际宽度换至第二行；对象操作靠近场景下沿，投影标签避让这些控件。温度切片图例独立排布方向、色阶、位置与有效范围，滑杆可直接操作。右侧详情收紧身份与异常摘要，将温度、功耗并列，小趋势及说明按需查看。

机房告警的资源列表直接列出当前有效活动告警设备，按严重程度、机柜和 U 位排列；支持级别筛选及设备/柜位多词查找，总数始终按全房有效设备计算。复查默认样本时，选“演示 → 告警排查”可回到模拟第 60 秒的全机房清单。首屏可对照 A01 柜的 SRV-07（U3–4，严重）与 SRV-08（U7，预警）；从各自安装位进入设备，展开后切到温度，再从页头返回原告警行。查找框、级别和全房计数留在左栏上方，设备行独立滚动。查找唯一匹配设备时可按 Enter 预览。每行以名称、级别、柜位和进风读数供比较。单击在安装位置标出设备短名、当前告警级别与轮廓。打开“查看告警详情”后，详情引用该设备的模拟判定依据，集中提供回看过程、定位安装位和查看内部。切换到资源栏的“列表”可查找全部资源。页头返回标明原设备。回看使告警降级或退出活动列表后，详情保留排查时刻、级别与进风读数，三维保留所选设备短名，仍可进入安装位或内部。原告警已退出时，安装图显示原设备所在位置。返回时机构先归位，恢复出发镜头、列表查找、级别、滚动与焦点，保留最新共享时间。宽屏同时还原详情栏的开合。原设备仍匹配时在该行标明排查起点；已退出或不匹配时，列表单列原设备与当前状态，焦点回到查找框。缺失、过期、离线及停机分别说明。原设备、所属柜及部件保留排查往返；无关对象、主动结束或固定演示画面清除，固定画面同时清空告警筛选。“列表”可按原层级浏览，进入机柜后继续沿用“仅看告警”筛选；机柜汇总和部件评估不重复计数，不提供告警确认或消除。模拟播放与明确的“分析”入口收入页头，完整曲线、共享时间及已发生事件使用同一个右侧分析栏，替换普通详情，不再叠加底部告警表与时间条；分析栏顶端可直接返回详情，标明播放状态与场景同步。Esc 优先清除搜索、关闭菜单/分析/详情，再返回空间上一级。中等宽度下资源与详情分时占位，普通选择或定位保留资源导航，明确查看详情时让出位置，避免三栏同时挤压模型；手机宽度下详情和分析接在场景后方，温度卡片完整容纳控制与说明。当前已验证资源进入、子件展开、告警范围筛选、回看保留姿态及桌面/窄屏布局；不代表移动触控完整验收或性能基准测试。设备模型与其余设施细节仍按下述计划精修。

统一工作区按实际用途收敛为“总览 / 温度 / 功耗 / 告警”：总览保留对象原材质与选择，支持位置和结构浏览，温度和功耗分别表达明确指标，告警通过场景与左侧资源筛选联动。机房总览默认收起右侧详情，将运行设备数、已知输入功耗与有效覆盖融入场景；选择资源后按需展示精简详情与小趋势，不再固定占用整列宽度；各入口共享选择与时间，不设置“数据”或“告警叠加”开关。环境、电力作为后续数据能力扩展后的领域名称再复核；空间容量与跨柜网络拓扑尚未实施，不显示空入口。

资源导航采用按层列表：机房列机柜与设施，机柜按 U 位从高到低列设备，设备内部按部件类别分组。名称同时显示类型、编号和位置；搜索支持中文类型、机柜、U 位和编号组合。输入安装坐标时按设备占用的完整 U 位区间匹配。例如 `A01 U24` 可找到占 U23–24 的 SRV-01，`B03 U27–33` 可核对该段的设备与前置盲板。机房层可查全室，进入机柜或设备后默认查所属柜，写明柜号可跨柜。定位安装位置会选中所在机柜内的设备并保留查询，从展开设备定位时先归位。装机角标按安装外廓绘制并跟随导轨移动。盲板按配置核对，不计为可分配容量。单击只选中与预览，不移动相机或自动展开；从设备行进入所在机柜，再查看设备内部；“定位”聚焦可见资源，部件使用定位操作。跨位置预览保持当前模型，切换实例前先让已抽出或展开的设备归位，并等待对应的场景就绪信号。

温度在机房和机柜层级按实际 U 位显示逐设备色条；功耗用机柜旁的预算标尺与 W/kW 标签表达，不把整台模型涂成指标色。设备内部保留已有部件表面着色，并增加跟随展开几何的部件读数。指标缺失与零值分开，数据变化与共享时间同步。

机房温度视图已直接接入水平切片，图例提供 0.20–2.10 米高度调节，并显示本层有效输入数与估计范围。模型 `intake-local-idw-v1` 只使用当前有效设备进风读数；代表位置按设备 U 位中心、机柜正面前方 0.08 米假设。按 X/Y/Z 方向 1/0.55/1 米的椭球邻域作紧支撑反距离加权，权重为 `(1-d²)²/d²`，仅估计机柜正面区域；最近代表位置无效时留空，不以邻居补成正常。结果与共享时钟同步，调高度和回看不触发镜头或结构变化。机柜标签显示“本层约”估计，右侧与机房汇总继续显示设备读数及最高值；它们与环境实测、排风及 CFD 结果分开。参数集中在场景 JSON，算法与渲染由独立代码实现。

机房温度图例可预览当前范围内进风读数最高的设备。水平切片按当前高度的有效输入取最大值，垂直切片按所选柜排取值，同温按设备编号稳定选择。图例将设备输入读数与切片插值范围分列。预览联动对象详情与安装位置，回看更新读数，选择停留在原设备。预览和返回保留手动镜头，返回时恢复原对象及资源栏、详情栏的展开状态。手动换对象、调整切片或载入固定画面会结束本次往返。展开图例的有效台数，可查看当前切片未参与估计的设备、柜位和原因；过期项列出最后观测秒数。连续预览这些设备可一次返回最初选择，手机点选后收起名单。超出局部插值范围也会留白。

机房资源导航增加“进风对照”，将八柜全部设备按统一 U 位坐标并列显示，每个色块覆盖整台设备的安装跨度；它使用现有整机进风模拟值，不受当前切片高度限制，不表示逐 U 测点或柜内连续温度场。柜卡列出最高有效值与覆盖率，无当前读数用斜线、未安装区用底色区分。逐台名单可在当前机柜和整间机房间切换，按安装位置或当前有效进风从高到低排列；同值沿用柜序和 U 位顺序，无当前值置后，不以零值补缺。可按设备编号、柜位和数据状态查找，并筛选有效进风或无当前进风；查找、排序与筛选不改变八柜分布、最高值或覆盖率。两种范围默认先显示设备名单，“机柜切换”可展开查看柜卡或选择单柜。预览同步所属柜位但不收窄整间机房范围，回看更新顺序而保留选择；高进风不等于告警。过期旧值只在最后观测说明中出现，离线、未配置与停机无进风值分别报告，不以零值补缺。

进风对照中预览机柜或设备保持镜头；垂直切片同步到所属柜排，离柜距离保留。从三维或清单选择机柜、设备后，名单同步到所属柜。普通水平切片里点选设备，原柜读数卡改为该设备的进风；从名单展开设备，再选 CPU 或内存，详情两列并排显示部件模型表面温度与同一时刻的整机进风。选中设备时常用入口为“安装位”和“固定为基准”，已有另一台基准时显示“对照分析”。机房气流、内部、详情和单对象分析收入“检视与分析”。选择其他设施时收起设备操作，已固定的基准仍可清除。中等窗口预览保留导航，明确打开详情或分析才让出导航。从设备检视、详情或分析可在页头返回机房进风对照。跨层时先复原、合盖和收回设备，再保留原机柜、查找、滚动位置、选择及切片设置；机柜内切换安装图或列表仍保留返回入口，回看后的共享秒数继续沿用。返回同时保留查找范围、排序和数据筛选；回看导致所选设备不再匹配时，保留所选说明与操作，焦点返回查找入口。双设备比较沿用同一查找上下文。载入固定演示画面清空本次对照状态及名单设置。桌面验收覆盖 1440×900、1024×768，正常动画与减少动态效果，以及八柜、数据质量、垂直切片、分析回看和结构往返。

进风对照当前设备提供“机房气流”入口，固定进入时的整机与查找上下文。沿用已有支路分段、设施端点预览、输入历史及安装位/内部检视；往返延续所查设备、所属机柜、制冷单元、对应格栅排和本机部件，不扩展为设施覆盖。返回原进风查找前先完成复原、合盖和收回，再恢复原设备、柜位、查找范围、排序、数据筛选、切片与列表焦点，保留最新时间；所选设备已不匹配时仍保留说明并聚焦查找。比较基准保留，原镜头和结构姿态不恢复。气流往返共用页头返回入口。收起两侧面板后仍可返回，焦点在该入口时 Esc 同样返回；无关对象、主动结束和固定画面清除往返。气流仍是既定方向假设与模拟输入，没有新增风口、风量、排风温度或测点。

进风对照可固定一台整机为基准，再选择另一台打开双设备分析。实线表示所查设备、虚线表示基准，两条曲线共用温度刻度、时间轴与游标；量程只取当前秒之前的有效观测，过期和缺失断线。差值固定为“所查 − 基准”，只计算同秒有效整机进风；两端预览不交换差值方向。悬停仅改变游标，两端读数随游标更新，点击、拖动或键盘回看才推进共享场景；共同冷却事件去重，两台设备告警保留各自身份。它不比较部件推导、不新增测点，不以温差判断异常、冷却效果或根因。

双设备曲线下可展开“温差过程核对”，列出截至当前秒数的有效时刻覆盖、最小/最大有符号差值及首次出现时刻；方向固定为“所查 − 基准”，有效零温差计入，过期旧值、离线、未配置和停机无进风值不补零。过程按两侧输入条件分段，不把数值波动当作事件。回看极值或区间首末秒时，冻结核对前的已发生记录范围；同框轮廓、柜前标签和整机读数跟随共享场景时间，曲线悬停不改变过程的当前状态。可返回核对前时刻并恢复入口焦点，保留镜头、结构姿态与当前选择；核对期间手动改变时间不扩写冻结记录，返回后继续随当前秒数更新。详情/分析切换、两端预览与设备内部检视保留核对基准，结构回到机房仍先安全归位。结束比较、更换基准、重播或载入固定画面清除过程状态。该范围只描述已有模拟读数，不表示异常阈值、冷却效果或根因。桌面验收覆盖正负差值、并列零值、过期边界、完全无效过程、同框与结构回看、窗口变化和时刻返回。

在温度名单固定基准并选中另一台设备后，可直接从机房温度场景图例同框，再从名单打开对照分析。读数框优先避开两台设备的安装跨度，引线沿用对应曲线的实线或虚线。跨柜时在原读数行并列显示柜号、U 位与进风温度。“同框观察两台设备”原位切换为“返回原视角”，收起分析后仍可返回。分析栏并排显示两台设备的进风读数，选择设备后共用一组安装位和气流操作，曲线口径按需展开。场景按既定 U 位在柜前标出完整安装跨度：① 所查为实线、② 基准为虚线，两端身份与曲线一致，不因预览交换。取景检查已登记柜体的遮挡，并适配桌面侧栏和窗口变化；保留深度测试，不透视柜体。场景标签始终显示当前共享秒数的整机进风或无效原因，图表悬停只改变游标。同框期间收起全柜温度色条和切片，读数沿用名单里的告警色，结束后恢复原视图；返回原视角恢复相机、观察中心和场景按钮焦点，保留所查与基准设备、当前选择及最新回看时刻。手动旋转/缩放、标准视角、定位、离开温度、结束比较、选择无关对象或固定画面会结束此次视角返回状态。设备检视期间不补画机房对端，沿进风对照返回入口安全归位后可继续同框；轮廓不是实际风口、供风覆盖或新增测点。几何检查覆盖八柜高低安装位任意组合，桌面页面验收覆盖同柜、跨排、数据质量转换、回看、窗口缩放、正常/减少动态效果及开盖展开后跨机型归位。

双设备分析可分别预览两端、定位安装位或查看机房气流；从任一端定位安装位后，展开并点选部件会切到部件详情，并排显示该部件的模型表面温度和所属整机在回看时刻的进风温度。预览保持镜头与结构。从展开的设备直接定位另一柜的安装位时，先在原柜收拢部件、合盖、收回托盘并关好柜门，再切换机柜。返回机房对照恢复原所查设备、查找、滚动和开始比较时的切片，沿用最新共享秒数。“单对象分析”结束此次比较并保留基准，选择无关对象也结束比较；基准可替换或清除，载入固定画面统一清空，不跨刷新保存。桌面验收覆盖两种视口及正常/减少动态效果、跨柜两端往返、游标与键盘回看、过期转折、离线/缺失/停机和展开结构归位。

同一图例已支持切换垂直方向，按场景明确登记的 A/B 排及真实机柜正面位置取样，范围为 0.20–2.10 米高度、距柜面 0.08–0.90 米；下限避开柜门与把手，防止表面重合。只使用所选排的输入，保留无效区域空白。垂直标签显示沿切面高度采样的最高估计，并注明“切面最高约”，不沿用水平“本层”口径。方向、机柜排、位置和回看保持当前对象、镜头与结构；图层切换保留各方向设置，载入演示预设恢复水平初始设置。切片保留真实深度遮挡，可旋转观察；它不代表气流或房间环境实测。

气流示意 `representative-airflow-v1` 使用独立气流视图，与温度视图共用数据与三维引擎。当前两排机柜同向朝 +Z，不称为封闭冷热通道；四种设备模型均明确登记“假设前进后出”。路径绑定已配置的冷却关系：低位沿空闲侧通道送至柜前地板格栅、升至设备 U 位后穿柜，再在 2.65 米高度示意回风。制冷单元出入口为逻辑端点，未识别真实风口；路径不表示实测风速、排风温度或 CFD 结果。参数、方向假设与色彩集中在场景 JSON。

气流机房画面默认取 A 排首柜中最接近 1.2 米的已配置运行服务器作一条代表支路；选中机柜/设备后仅显示其对应路径，部件沿用所属设备。气流目标不读取温度切片参数；所查设备、机柜或格栅排决定代表支路，可选垂直叠片跟随该支路柜排，不反向改变目标。送风蓝、穿柜浅青、回风灰米色分别表示路径环节，不使用告警色；送风线明暗随冷却输入变化，不推算风量或风速。粒子使用共享时钟的绝对时间，暂停、回看与倍速不依赖上一帧积分；停机、维护、离线、过期或缺失对象保留灰色静态方向，减少动态效果偏好下只留箭头。设备内部和镜头转场不显示机房流线，避免与结构探索重叠。

送风逻辑端点、柜前地板送风、设备进风及柜后上方回风假设使用四个单行短标，标签引线随相机投影并避让图例、工具及其他标签。设备前后柜面以细框标出其实际安装 U 位的代表范围，替代进风圆环；柜外固定方向箭头在暂停及减少动态效果时仍保留。穿柜段与其他环节共用深度遮挡，可切换前/后视或旋转观察，不以透视线穿过不透明柜体。细框不是设备真实风口或排风测点。格栅行与铺设网格由场景 JSON 统一定义，路径绑定目标柜所在排的最近格栅中心，不再独立猜测地板端点。仍采用低位侧通道送风的布置假设，未建立架空地板风腔、实际风口或封闭冷热通道；回风返回制冷单元逻辑入口，不生成排风读数。送风标签显示公共冷却输入，进风标签只显示有效运行设备的模拟温度；停机、维护、离线、过期及缺失对象以灰色静态路径和具体原因替代当前温度。右侧“气流端点与依据”提供可用键盘查阅的支路身份、机柜/U 位、完整端点读数与边界说明，投影放不下或端点离开画面时仍能查阅。暂停及减少动态效果时保留静态方向箭头。当前按 1440×900 与 1024×768 桌面视口验收；早期气流还曾检查窄屏布局，不代表当前手机端验收或性能验证。

气流视图的场景操作区用一个范围选择器切换全路径、送风与格栅、设备进风、柜后回风四种观察。取景沿当前代表路径计算并避开控件，三维强调当前段、保留其他段的淡线参照；端点短标只保留当前段相关项。打开“端点与路径依据”时，右栏先解释当前观察段的端点；可就地切换送风、格栅、进风和回风，一次只列该端点的读数与操作。切换查阅端点保留原镜头和对象，明确预览后才改变选择。分析先显示曲线，路径依据按需展开。首次观察记录原镜头，连续切段后仍可返回；操作区 Esc 同样返回，焦点回到气流观察范围。共享时间、对象和结构不回退。气流默认不叠加切片。叠加后，方向与估计色标同排显示，滑杆旁保留位置与单位，垂直叠片标明目标柜排；叠片参数独立于温度视图，切换视图或层级后收起，固定画面重置参数。回看和端点预览保留当前段，窗口与侧栏变化重新取景；手动镜头、标准视角、定位、无关对象、支路变化或离开气流视图结束镜头往返。自动建筑剖切沿路径补充视线采样，柜体与设备仍保留真实深度遮挡。从机柜、设备场景或详情的“冷却关联”查看机房气流时，机构先归位。镜头在图例上方或右侧选取能放大整条代表路径的画幅，叠片展开后重新适配。页头返回原对象时恢复原图层、镜头、结构姿态和侧栏；从详情进入还恢复原趋势指标和展开位置，焦点回到发起操作的按钮。

气流说明和分段近景提供“对照输入与进风”，固定进入时可见支路的显式制冷源与整机身份，在现有分析栏显示冷却输入百分比及本设备有效进风，两条曲线分别保留单位、共用游标和时间轴。垂直切片中所选对象位于另一排时，对照当前画面的代表设备，不误用原选择或范围最高值；端点预览后的固定支路也可继续对照。悬停只更新两条曲线游标，回看、事件选择与重播更新共享时钟，三维读数、静态/动态条件同步，保持观察段。停机无进风，过期断线，离线与未配置留空；维护时有效进风仍可对照，路径继续遵守静态展示规则。公共冷却输入事件独立于设备采样质量，设备事件仍截至最后有效观测，不生成新的设备或设施告警。返回恢复原详情/分析、导航、分析滚动及入口焦点，保留最新时间和当前观察段，查找与筛选不被改写；普通观察保留镜头，近景随画幅适配。缩至中等窗口时让出资源栏以保留分析。切换对象、图层、主动定位、关闭分析或固定画面结束本次对照；气流叠片设置不结束对照，重播沿用同一支路。仅在机房已显示的支路开放入口；设备内部先沿原气流入口安全归位。百分比不是风量、制冷量或设施功率，进风不冒充排风，不从曲线先后推断实测冷却效果或故障根因。

柜前 34 处格栅与地面开口共用铺设网格和尺寸配置。面框、横条顶面与原地板齐平，条间保留浅凹背衬，地面分格延续原世界坐标；不再把格栅条块叠放在完整地板表面。几何按面框、横条、背衬合并为三个实例批次。气流视图用细轮廓标出当前代表支路对应的格栅，替代该处悬空圆环；供风路径保持原网格取整及低位侧通道假设，切换柜排、设备或回看同步对应，无效观测保持静态灰色。格栅没有独立读数或告警，浅凹结构不代表已建立架空送风层、实际风腔、风量、阻力或工程开孔率。

现有格栅按 A/B 两排接入“建筑与布线”，每排可搜索、预览、点击及定位；面框、横条和背衬的实例身份均映射到所属排，仍使用原来的三个实例批次。详情显示配置高度、单处尺寸、数量、整排外缘跨度及对应四柜，机柜的“柜前送风格栅”可反向预览或定位。关系中的代表落点沿用气流使用的最近格栅规则，不表示每处格栅只服务某柜。气流路径说明可直接预览或定位当前落点所在的格栅排；气流视图选中格栅排时观察该排代表路径，温度切片的手选柜排不改变气流目标。跨设备定位先归位，回看保留布置；格栅没有运行曲线、独立读数或告警，不参与设备汇总。桌面验收覆盖两排查找、场景拾取、双向关系、气流入口、时间分析边界及展开设备返回。

格栅排详情的“对应柜排”列出每柜的代表设备、U 位和最近格栅。代表设备按配置高度选取。“查看代表气流”沿既有端点和流向观察支路，气流操作区的设备编号可直接进入安装位。页头的“返回格栅布置”标明来源机柜，在分析、侧栏收起或结构菜单展开时均可使用。返回先归位机构，再恢复原格栅排、图层、指标、切片、资源查找和筛选，列表回到原支路的滚动位置与按钮焦点。机房起点恢复进入时的镜头和观察中心；从设备内预览格栅起步时，返回定位到机房中的格栅排。两种起点均保留最新模拟时刻。选择无关对象、主动结束或载入固定画面会结束往返。此前已核对两排八柜的支路配置，本次桌面实测覆盖 B03 格栅 11、SRV-54 安装位及展开结构往返。

功耗对照还可切换“整间机房”，跨八柜查找全部设备，并按当前功耗或配置预算占比从高到低排列；安装位置顺序可随时恢复。两种范围都可展开“机柜切换”。默认名单按两行显示名称、读数与安装位置，有效零值和未计入原因就地标出；按预算占比排列时主读数切换为百分比，全机房结果带柜位。选中设备后可对照精确功耗、配置预算与占比。未知读数置后，有效零值仍参与排序，同值沿用柜序和 U 位。排序随共享时间更新，但所选设备身份保持；深入检视返回保留查找范围和排列方式，固定画面恢复本柜预算占比降序。默认演示从模拟第 60 秒开始，A01 的 SRV-01（整机预算 240 W）已持续超预算，SRV-10（235 W）接近预算。展开两台设备时，CPU 和内存各自按部件预算判定。高占比不等于高功耗、告警或容量不足，筛选与排列均不改汇总口径。

机房内从清单或三维选择机柜、设备时，功耗对照同步所属机柜和操作对象。在功耗名单点选设备后，原柜旁的读数改为该设备的输入功耗和自身预算占比；主动查看供电支路时优先保留端点。选择设施后仍可浏览原名单，收起机柜和设备操作；筛选移出所选设备时就地提示。在固定操作区可进入安装位、内部、详情或分析，并沿既有 A/B 供电配置观察端点与单部件。页头提供“返回机房功耗对照”，收起资源栏后仍可使用。返回宽屏名单时恢复进入前的详情开合。跨层返回时先安全归位，再回到原柜和原对象的功耗对照，保留对照查找、数据分组、名单位置和最新共享时间；原设备移出分组时保留其当前解释并将焦点交还柜卡。返回不重开旧设备，也不恢复旧镜头。无关对象、主动结束或固定画面清除往返；固定画面同时清空对照条件。中等窗口资源和详情分时占位，温度与功耗切换保留各自查找条件。该能力复用模拟整机输入及配置预算，不推断设施容量、节能效果、A/B 分流或新增计量点。

时间分析的功耗曲线可打开“对照有效设备预算”，实线为有效输入，虚线为同一批有效设备的配置预算，两线共用 W 刻度、时间和游标。游标同步列出预算、占比与有效覆盖；悬停不改变场景秒数，点击、拖动或键盘回看沿用共享时间和当前镜头、结构姿态。整机、机房、机柜、配电柜和 PDU 沿用输入核对口径，过期、离线与缺失不补零；停机有效零值仍保留预算。覆盖变化会改变预算虚线，不将全部配置预算画成当前分母；部件与冷却对象不显示此项。可关闭对照恢复单线，或沿现有返回入口回到详情及功耗名单。预算差距不是可用容量或节能空间，设施仍未独立计量。

功耗输入核对可展开“预算口径过程”，从初始口径开始，只记录已发生的计入条件变化，普通功耗波动不另造事件。变化项列出设备身份与前后条件，分别回看变化前一秒和变化时刻的有效功耗、对应设备预算、覆盖数及占比；A/B 按关联整机去重，有效零功耗继续计入其预算。首次回看固定当时已知记录与返回时刻，连续核对、查找、详情/分析切换和窗口变化保留基准，三维标尺与当前名单仍跟随共享时间；返回核对前时刻归还标题焦点。Esc 收起过程；切换范围、指标、关闭输入核对、重播或固定画面清除基准。占比变化不等于节能、容量变化或支路分流。已在两种桌面视口及普通/减少动态效果下核对机房、机柜、配电柜和 PDU，覆盖 44→45 秒过期边界、无口径变化、筛选保留与时刻返回。

温度图例中的输入覆盖与设备对照共用一组展开状态，一次只展开一项；长内容在各自区域内滚动，保留切片方向、柜排、色阶与位置滑杆。说明内容支持键盘滚动，Esc 收起当前项并返回标题焦点，不关闭右侧详情或分析；展开、收起及切换说明接管巡游，保留所查对象和共享时间。

机房温度图例可按需“对照所查设备”，分别查看整机有效进风和该机柜前方当前切面的局部估计，列出安装 U 位与进风代表高度。选中其他柜排、切面远离设备高度或输入无效时说明对应边界；柜前估计仍可能来自附近其他设备，不能当作所查设备读数。可按现有滑杆步长调整到设备附近：水平切片取邻近安装高度，垂直切片选择所属柜排及邻近进风代表位置的离柜距离；随后可返回原切片设置。对齐不改变选择、镜头或共享时间，回看更新读数，手动改变切片后不再显示旧位置返回入口，切换所查对象结束该次往返。

切片对照可从“核对估计依据”进入右侧详情，沿同一插值计算列出当前柜前位置附近的输入、最近输入及计算占比；重合位置直接采用该输入，最近输入无效时保留空白，其他有效邻居也不补值。三维小方框标记估计位置，圆圈/叉号区分有效输入与无当前值，选择一项后仅用一条静态虚线对照位置；标记保留深度遮挡，不参与拾取或接触阴影，该核对仅在温度视图开放。预览输入保留原设备的对照与切片对齐返回状态，可返回原设备；标记、预览及回看不移动镜头。“观察估计位置”从柜前近看当前位置和附近输入，取景避开图例与顶部工具，后排从排间通道观察；近景包含无效输入，读数与质量变化不重新构图。主动调整切片位置或画幅变化时重新取景，可单独返回核对前视角，返回原设备对照也会恢复该视角。手动旋转、缩放、自动环绕或选择标准视角结束此次视角返回状态，保留用户接管后的镜头；结束核对也不强制回退。共享时间、切片高度、柜排和距离改变时重新核对；其他柜排不借用读数，过期、离线、未配置和停机没有当前输入占比，小于 0.1% 的正占比不显示成零。关闭核对、收起详情、选择无关对象、离开机房或温度视图、载入固定画面结束此次核对。该能力只解释所查位置的局部插值，不代表整张切片、独立环境测点、真实热贡献、风量或置信度。桌面验收覆盖 1440×900、1024×768，包含正常动画与减少动态效果下的前后排近景、远离柜面的切片、视角返回、分析栏切换、手动接管、输入预览返回、切片对齐恢复、跨排、数据质量与结构归位后核对。

当前已有机房水平/垂直进风温度切片与气流示意、两处环境探头的温湿度演示与推导露点；安装空间核查已实现，可分配容量和跨柜网络拓扑视图尚未实施。曲线与量程仅使用当前时刻之前的观测；过期与缺失保留空缺，停机零值有效。真实设备接入、浏览器兼容性和性能基准未在本轮扩展。

### 场景、图层与操作

以“对象 × 数据图层 × 时间”组织体验。保留一个连续的三维场景、同一对象选择与共享时钟。结构拆解融入对象操作，不再和运行状态并列为观察模式；默认总览视图保留原始材质与选择标记。机柜开门、设备抽出、开盖、展开与复原随所选对象出现，切换指标后仍可操作。温度与功耗视图直接呈现各自指标。

主入口使用直接、可验证的名称，暂不以未实现的能力概括现有数据：

| 入口 | 回答的问题 | 当前范围 |
| --- | --- | --- |
| 总览 | 当前有什么、在哪里、内部如何组成？ | 机房与机柜浏览、资源预览、设备结构及对象操作 |
| 温度 | 哪里温度较高？ | 设备进风与部件模型温度，分别标记数据口径 |
| 气流 | 当前代表支路经过哪里？ | 已配置路径、端点与流向，温度切片按需叠加 |
| 功耗 | 当前用了多少电、占预算多少？ | 输入功耗、已知汇总与预算占比，不推断上游电源关系 |
| 告警 | 哪些对象异常、在哪里？ | 与温度、功耗同级的场景与告警列表，支持筛选、选中和定位 |

门开、维护、离线、数据过期分别表达，不统一算作故障。总览为默认入口，缺少的房间环境测点不沿用到部件；模型部件评估不进入设备告警计数。

### 布局与信息取舍

工作台面向两种连续的使用情境。第一次看机房的人先靠柜排、材质、尺度和轮廓认出空间；带着告警来的人要能从同一画面找到具体设备、追溯读数、回到原清单。两者共用模型和时钟。浏览时给模型留出轮廓和周边参照；排查时把注意力引到一台设备或一条关系，其他对象保留足够的明暗和深度，帮助判断位置。

| 区域 | 面向用户的问题 | 模块组合与取舍 |
| --- | --- | --- |
| 顶部 | 我在哪，怎样回到刚才的任务？ | 面包屑只记录物理层级。从清单进入专项检视时，在固定位置提供带目的地的返回动作；收起侧栏、切换分析或调整窗口后仍可达。关闭分析回到对象详情，结束任务留在当前位置。 |
| 左侧 | 在这个范围里找谁？ | 浏览显示资源目录，排查显示当前任务清单。行内留下便于比较的身份、位置与状态；选中后再给当前对象的操作。进入专项时让出无关查找工具占据的空间，返回恢复筛选和键盘焦点。 |
| 场景 | 对象在哪里，结构或关系怎样变化？ | 保留对象轮廓和操作端点。柜门开合、导轨和开盖沿真实装配方向运动；关系用端点和方向标表达，暂停时仍能顺着读。标签提供身份、必要读数与单位；已有分段和箭头能说明的路径，省去重复说明句。 |
| 右侧 | 这个对象怎么了，依据是什么？ | 身份与范围放在读数旁，优先解释当前任务。告警先看触发指标与过程，点开分析后由曲线和事件占据同一栏。配置明细按需查阅；影响判断的缺失、过期、离线、有效零值和演示属性在读数处可辨。 |

普通单击同步场景选中态和已打开的详情；详情收起时，选中、聚焦和逐层浏览都保留用户的侧栏布局。机柜与设备使用独立检视工位。机房内定位保留原柜排，进入检视时过渡到两侧长弧渐隐的方位盘。正面单标和背面双标固定，外弧对应观察方向，普通动效下分段光轨缓转。设备先水平出柜，再调平落入带侧边导光槽的检修托架。到位时光迹沿托架边缘从后向前走一次。展开时两片托架先横向分开，再下沉，在原机箱底面下显出定位线，单看部件时隐去定位线，落台取景同时容纳机箱和两半托架，展开后按可见部件的目标包围盒分别投影，绕设备旋转保留中心和手动缩放比例。普通返回机房恢复出发镜头，专项返回使用其记录的视角。单部件和盘组按各自范围取景。

Chromium 在 1024×768、1440×900、1920×1080 的正常动画与减少动态效果下，逐柜点选了 8 柜共 84 台设备的前面板，并核对空置封板。四种机型均核对落台底面。SRV-07、STO-02 核对展开后的手动转向、画幅边界和逐层返回，内存模块另核对单部件检视与恢复完整结构。

**后续修改与验收**：动手前用一个具体对象写清入口、要回答的问题、被替换的模块和返回目的地。重复展示一个数值必须有不同用途，例如用清单比较多台设备、用场景标出其中一台的位置。按钮用可预测的动词和对象；无关动作随任务退出，保留键盘可发现性。首屏拥挤时先调整内容归属，再调字号与间距。清单中一项有多个可选位置时，行内只给比较所需的摘要，展开后选择具体位置，共用一个进入动作。往返验收须选一个非默认位置，并在深入后改动局部选择，检查返回是否仍落在原位置。

以 1440×900 和 1024×768 在实际页面连续检查默认、选择、深入和返回。使用默认的对象标签密度，观察环绕中标签与模型的遮挡，再暂停或使用减少动态效果检查静态方向。组合最长对象名、两栏切换以及当前任务的异常或无效读数。验收时能直接指出当前空间、所选对象、读数范围和返回目的地；同时核对返回后的时刻、焦点与机构姿态。对带操作的对照名单，交替从名单和三维点选，再选名单之外的设施，逐次核对按钮实际打开的对象。镜头操作集中在场景，详情能查阅两端并处理当前对象。逐一检查两栏中同名按钮是否做了同一件事，有专项返回入口时，再收起资源和详情验证镜头、时间和键盘焦点。前后截图取相同状态。

告警排查和九组布置图往返已在 1024×768、1440×900、1920×1080 下实测，每档均覆盖正常动画与减少动态效果。布置图覆盖连续查找预览、进入机柜、查看设备安装位、核对顶灯与桥架交叉高度、沿柜前格栅观察代表气流、检查环境与安全设施（检漏、探头与烟感）、核对入口门禁、从制冷服务范围深入设备，以及从配电柜经 PDU 插座追到设备电源。三档均从手动调整的机房视角出发，在菜单展开时点击返回，核对原对象、视角、查找、滚动、键盘焦点与最新回看时刻。

同样三档桌面尺寸和两种动态效果还覆盖交换机端口、风扇和存储盘位的完整往返。端口覆盖机房与机柜的两端预览、部件及安装位、接入分支切换、未配置端口，以及从交换机内部返回安装位。四种机型的风扇均核对前后侧、单件切换与返回整组。存储核对从正面盘组进入单盘和中板接点，换盘、回看后返回原盘位焦点。两类部件均在菜单展开时实际点击返回，核对展开比例和最新时刻，最后跨层归位到机房。

机房网络接入总览、功耗排行与预算回看、功耗输入名单、进风对照、温度切片、A/B 供电近景也已补齐上述三档和两种动态效果。网络从机房名单沿连接两端进入安装位和部件，再回到原分支与列表行。功耗回看区分有效零值与过期输入，输入名单在读数跨越有效期后仍可返回原查找。进风对照覆盖双设备同框、深入安装位，以及从名单和对照对象转看气流。温度切片核对两排和离柜距离，供电近景核对单路与双路、插座与设备输入。镜头往返以出发前手动调整的位置为准，回看沿用返回时的模拟时刻。

环境与安全设施、检修空间和巡游接管也按同样三档尺寸与两种动态效果复验。双探头对照覆盖温度、相对湿度、推导露点以及采样不同步、过期和离线。检漏覆盖全线、引线、感应段和封端，烟感从两个起点分别核对。空间核查覆盖沿排四组通道、柜前后视角、机房空段与柜内占用设备的逐层返回。巡游覆盖九个章节的循环、暂停续播，以及拖动镜头、切换图层、查找资源和设备归位期间的手动接管。

桌面主工作台已按机房、机柜和设备三层逐一复核总览、温度、气流、功耗和告警，并检查资源呈现、详情、时间分析和跨层返回。三档尺寸与两种动效均在 Chromium 操作。当前对象为机房时，收起右栏后从“对象详情”进入；模拟播放和暂停固定在页头，分析栏用滑块回看。演示、显示和结构菜单在点击外部操作时收起；在菜单内按 Esc 先关闭当前展开项，保留资源栏的查找词。

机房总览从列表、布置图、空间核查和网络接入查找对象。其余四个视图在资源栏标题下固定排列本视图的清单和“列表”。温度进入进风对照，气流可按柜选取代表设备路径，功耗进入功耗对照，告警进入当前告警清单。“列表”始终查找全机房资源。机柜从安装图看位置和指标，空间核查在总览办理；设备从部件目录定位。柜前以凹入的暗色平板标示未装设备的 U 位，指向设备或封板可读编号和安装位置。气流入口采用所选对象的配置关系。静态设施的尺寸留在详情，时间分析说明该对象是否有历史记录。

**当前收敛顺序**：告警清单先定位所选设备，明确查看详情后进入排查。气流场景保留观察范围、端点和返回，路径依据放在详情。存储核对的盘组用盘位图，单盘和中板接点用紧凑选择器。场景操作条标明所看范围，收起详情或回看时仍可返回盘位；完整结构和复原外观分别对应展开和装配两种目的地。风扇与盘位核对共用固定位置的返回按钮和结构菜单。场景负责风扇前后侧与盘组正面取景，右栏用一行风扇编号或四列盘位图选件；所选盘位的行列显示在图标题旁。验收时在同一侧栏状态下比较整组、单件、中板接点的按钮位置，并实际点击菜单周围的操作。风扇整组切换前后侧，调整展开比例后按机构终态重新取景。单件可就地换扇，回看后的返回按钮写明原核对侧。普通部件的同级切换和逐层返回也集中在场景操作条。新增结构操作先用关闭详情和打开时间分析两种状态走通；两种状态下都应能从当前子件回到所属模块，再回到整机。每轮验收一条往返后再推广到其他模块。

### 三维表现与数据含义

真实金属、塑料、PCB 与建筑材质形成底层质感；界面使用低亮度中性底色、清晰文字和少量强调色。运行状态色与指标色阶分开：正常、预警、严重通过颜色、形状和文字共同表达；高功耗或热图暖色不直接等于故障。机房的墙地、工作台与检视工位使用同一组冷色调，保留设备本身的材质。温度从蓝、青经黄色过渡到橙红，功耗用条长和百分比表示预算占比，常规用蓝色。演示默认达到 90% 时转琥珀色，严格超过 100% 连续满 5 秒转红；回到预算内按当前占比恢复，数据失效中断计时。规则允许按对象覆盖。机柜标尺只表示整柜占比，柜名旁的小符号提示柜内整机预算状态，部件推导留在设备层，不计入进风告警。功耗视图按需展开供电接入，核对配电柜、PDU、设备电源或追踪支路时直接显示对应端点。设备开盖或展开后保留机箱材质，按部件读数着色。模型、切片、占比条和对应图例共用指标色阶。气流分别用青蓝、浅绿和浅铜色标识送风、穿柜和回风。分析视图降低检视背景亮度并收起装饰光轨。

| 维度 | 三维表现方向 | 约束 |
| --- | --- | --- |
| 温度 | 设备表面热图、可移动水平/垂直切片、热点定位 | 进风、排风与部件温度分开；测点、插值和模型推导有可查依据 |
| 湿度与露点 | 环境测点与局部区域，选中后查看关联读数 | 不给每个部件编造湿度；稀疏测点不直接冒充精确体积场 |
| 气流 | 有方向的流线与粒子，必要时叠加温度切片 | 先核对送回风、柜体前后及通道关系；示意模型不宣称 CFD 结果 |
| 电力 | 设备负载着色、柜侧刻度、选中对象的明确供电路径 | 区分 W 与 Wh、实测与预算；路径动画须有已定义端点 |
| 容量 | 空闲 U 位立体槽块、局部透视、安装范围与尺寸 | 占用、预留、不可用分别表达；连续空间依据真实 U 位配置计算 |
| 告警与事件 | 局部轮廓、定位线和短暂脉冲，点击进入事件 | 避免全场持续闪烁；发生、恢复、影响对象和推断关系分开 |

一个主着色图层可搭配少量辅助流线与所选对象定位标记，避免多个色场竞争。动效要表达方向、过程或注意力；减少动态效果偏好与低画质路径仍能读懂数据。雾效、泛光和粒子不能遮住模型、文字与选择反馈。

### 趋势与时间联动

对象小趋势跟随当前图层；展开后查看完整曲线、对比指标与事件。拖动时间时，三维读数、热图、气流模型状态、汇总和告警同步；相机与结构展开姿态保持当前操作。粒子位置是视觉动画，业务值由统一时间快照决定，不依赖上一帧积分才能回看。

当前为 120 秒确定性演示。新增环境输入须记录位置、单位、来源、质量、模型假设及时间响应；未来历史数据接入另行设计。回放、场景巡游和镜头环绕分别控制，不能把环绕动画当作指标变化。

## 领域设计原则

| 信息 | 基本约束 |
| --- | --- |
| 空间 | 明确坐标、单位、父级与稳定 ID |
| 资产 | 型号定义、安装实例与实际部件分开；槽位显式映射到模型节点 |
| 关系 | 网络、供电、冷却与成员关系分别建模，端点明确；不硬塞进单一空间树 |
| 状态 | 指标附单位、来源、观测时间与质量；健康、通信与告警分别记录 |
| 时间 | 所有视图共享时钟；模拟、实时与历史回放模式明确 |

设备既有机柜位置，也可有超节点成员身份；CDU 可关联多个机柜。关联不依赖显示名、数组顺序或猜测槽位，未知映射保持未知。

渲染层读取领域状态，模型通过映射关联业务 ID；选择、告警、搜索与拓扑共用对象标识。镜头动画不修改业务状态。模型姿态、部件配置信息和可逆爆炸编排按 [资产流程](../assets/README.md) 维护。

指标、告警与回放消费同一模拟状态，不让面板各自随机。相同输入和模拟时间得到一致结果；测量、模拟、派生汇总与推断明确标记。后续多源采集需定义更新、迟到和过期数据的合并规则。

功耗按设备、机柜和设施的计量边界汇总，标记覆盖率，区分转换损耗、未计量与缺失。零值有效，缺失、过期和离线分别表达。告警有稳定身份、严重度、对象及发生/恢复时间，考虑持续和恢复条件。相关异常不直接称为已证实根因。

## 渲染与技术选择

远景使用点位和简化几何，进入对应层级再加载细节。重复设备复用模型与材质，退出和取消加载时释放资源或使用有界缓存。示意与精确模型区分展示。

先验证桌面浏览器体验，再确定设备规模、画质与其他端适配。性能结果附设备、浏览器、对象规模、采样方法和限制；有原型后再制定可测预算。

原型采用 React + TypeScript + Vite，Three.js 负责参数化场景、射线选择与镜头控制。领域对象与层级状态、渲染对象和模拟时钟分离，使用稳定 ID 映射；重复静态几何按材质合并，远景按机型使用实例化外观简模，当前查看设备切换对应详细结构，缓存上限为已定义的四种配置。场景定义与经维护者授权的原创贡献模型作为资产登记；GLB 部件通过显式节点契约关联 ID，加载失败有简化结构提示。使用局部面光源、细节接触阴影和低对比程序化表面纹理增强材质层次，保持标准渲染降级路径；阴影及后处理资源随引擎释放。渲染与交互代码为 Apache-2.0。地图方案、服务端与持久化尚未确定。

温度切片、代表气流、指标标尺、网络/供电标记、通道范围和告警符号显式登记为数据图形，在接触阴影计算中整组排除，避免把切面当成实体板、把关系线当成实体管线。正常颜色绘制、深度遮挡、拾取规则及显示条件保持原定义；具有相同透明材质的实体不据此排除。

细节阴影的法线与深度计算排除文字精灵，避免 U 位短标、机柜名称等透明文字矩形被误当作实体遮蔽物而留下暗块。文字仍由正常画面通道绘制，保留各自的深度遮挡规则；不关闭整场接触阴影，也不改变模型材质、选择或指标口径。绘制结束及异常退出均恢复原可见性，原本隐藏的标注保持隐藏；标准画质沿用直接渲染。桌面验证覆盖前后视、设备抽出、回看与细节阴影切换，仍未代表跨浏览器或性能基准验收。

静止观察按需提交颜色与阴影绘制：暂停模拟、镜头与机构动作结束、选择角标收拢后，不重复绘制相同画面；对象、时间、图层、切片、画质、模型与尺寸变化会使下一帧刷新。相机环绕独立运行，机构过渡、选择收拢和播放仍持续绘制，过渡结束补绘包含接触阴影的终态。已有风扇展示动效随模拟暂停，不代表真实转速；减少动态效果下不连续绘制播放动效，仍随模拟快照和操作刷新。页面隐藏或图形上下文丢失时暂停引擎帧计算与绘制，恢复显示或重建场景后重新绘制；迟到模型与失败重试仍保留镜头、对象、结构和共享时间。

本机 Apple M5 Pro（ANGLE Metal）、macOS 26.6.2、Chromium 147、DPR 1，使用八柜 84 台样板的机房浏览、设备内部与时间分析预设，暂停且启用减少动态效果，稳定后各采样 2 秒：1440×900 与 1024×768 的完整场景绘制调用由每段 210–241 次降至 0 次。该计数只衡量重复绘制提交；未测功耗、温度或整体帧率，不能换算为相同比例的性能提升。该轮只优化绘制提交；后续帧调度结果见下文。

场景标签与引线按变化更新：投影位置或可见性改变后立即避让，控件展开、文字尺寸、侧栏、滚动与窗口尺寸变化合并到下一帧处理；静止时不重复写投影位置或读取控件边界。屏幕坐标归一到 0.01 像素，不改变三维位置和镜头；标签重新出现、切换固定画面及场景重建会重新绑定，卸载取消待处理布局。同一设备、浏览器和样板规模，减少动态效果、暂停在第 60 秒、拆分前的机房温度视图展开气流说明，稳定后采样 2 秒：1440×900 与 1024×768 的标签避让视口边界读取均由 240 次降至 0 次。该结果仅验证静止重复布局已消除，不代表整体 CPU、功耗或帧率改善。桌面交互验收覆盖正常与减少动态效果、工具展开收起、输入预览返回、时间分析、镜头旋转与缩放、窗口缩放及设备安全归位。

详细模型按四种设备机型和两类设施分别记录加载状态。制冷单元与配电柜随场景加载；机房预览和机柜安装图沿用简模，进入设备结构检视才请求对应机型，巡游也遵循同一规则。未查看机型显示“按需加载”，不当作加载失败；在途请求复用，已成功模型在当前场景内缓存，最多四种设备配置。离开设备后允许已有请求完成并缓存，不切回旧对象或移动镜头。加载期间可使用简化结构完成选择、展开与返回，结构就绪不再等待无关资源；场景重建也先使用当前机型的简化结构。模型请求或解析失败时保留简化结构，可从资源提示只重试失败项，不自动反复请求。加载成功和重试均保留当前选择、镜头、结构、图层与共享时间，交换机、存储展开后仍为配置示意。模型请求有 30 秒取消期限，销毁场景时取消在途请求并丢弃迟到结果。模型状态不代表设备离线、数据缺失或告警。桌面验收覆盖 1440×900、1024×768 的按需请求、慢加载导航、跨机型迟到结果、缓存、失败重试、结构与时间分析；未代表性能基准或所有浏览器验收。

模型传输采用构建时生成的 gzip 无损副本，浏览器使用原生 `DecompressionStream` 解包后交给原有 GLB 解析与部件契约；不支持原生解包时直接请求原文件。仅压缩已获准且摘要匹配的登记模型，收益不足 10% 或 16 KiB 的文件保留原传输。损坏、截断、超时和取消沿用明确的失败/重试，不自动额外下载原始大模型；静态服务已解包的 GLB 不重复处理。源 GLB、贴图、材质、节点与许可均保持原字节，压缩副本只在开发服务或构建时生成，分发清单附传输文件及还原文件的摘要和长度。为保留兼容路径，构建包同时包含原文件与压缩副本，包体积会增加。

本机 Apple M5 Pro、macOS 26.6.2、Node.js 24.14.0 与 Chromium 147，八柜 84 台样板逐一进入四种设备检视，以构建文件长度和浏览器资源计时的 `encodedBodySize` 核对传输量。当前六个模型原文件合计 43,330,628 字节，选择压缩或原文件传输后合计 22,308,661 字节，减少约 48.5%；其中 1U 服务器由 19,938,844 降至 9,675,177 字节，2U 服务器由 20,782,992 降至 10,632,282 字节。制冷与配电模型同时压缩；交换机与存储收益不足，继续使用原文件。计数为模型响应体，未包含请求头、页面脚本或纹理解码内存，不能换算为耗时或帧率提升；实际体积随模型和构建环境变化。解包后的模型规模、GPU 资源及 JavaScript 大包提示仍需后续专项优化。已在 1440×900、1024×768 核对开发与构建产物的压缩/原文件路径、四机型装配/展开/单部件检视、时间分析和安全返回，覆盖正常动画与减少动态效果；损坏重试及跨机型迟到模型保留镜头、选择、结构与时间。兼容回退以关闭原生解包能力模拟，未代表其他浏览器实机验收。
