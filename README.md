## 项目介绍

浮城（Mirage）是一个面向数据中心的三维数字孪生个人项目。它以地图为入口，从园区、建筑与机房逐层深入机柜、设备和内部部件，将宏观的空间布局与微观的设备结构连接起来，构建一个可以浏览、探索和交互的数字世界。

项目规划通过机柜开合、设备抽出、结构拆解与爆炸图呈现设备形态，并结合网络、供电及冷却关系，关联功耗、温度、健康状态和告警等运行数据。借助空间定位与历史回放，让设备在哪里、如何连接、正在发生什么，都能在同一个场景中被观察和理解。

> 当前已有八机柜、六十四设备的本地三维原型，可从机房进入任一演示机柜和设备，支持选择、镜头聚焦、旋转、缩放、9 个部件模组的爆炸展开与复原，以及 28 个子件的独立选择和聚焦。温度、功耗和告警在三维工作区各有观察模式，共用一个可回放的冷却扰动模拟场景。宏观地图、完整关系网络与真机接入仍为建设目标。未部署在线演示。

## 探索路径

**中国地图 → 园区 → 建筑 → 楼层 → 机房 → 机柜 → 设备 → 部件**

空间浏览、设备结构、网络/供电/冷却关系与运行数据相互关联。超节点作为可选的设备成员关系与专题视图，成员保留各自的物理位置。

第一版先贯通：**一个园区、一栋建筑、一个机房、八个演示机柜、一款复用到六十四台设备的可拆解结构、一个可重复播放的告警场景**。模拟数据明确标记，所有视图共享对象标识与时间线。详细边界与交付步骤见 [项目设计与路线](docs/project.md)。

## 当前运行与检查

原型使用 React、TypeScript、Vite 与 Three.js。建议 Node.js 24，最低 22.12；首次安装依赖后启动本地开发服务：

```bash
npm install
npm run dev
```

打开终端显示的本地地址。默认从机房总览进入运行态势并自动巡游，运行回放从混合状态的第 60 秒开始，依次展示开门、抽出、设备展开、散热细节和复原归位，最后回到机房循环。章节进度在模型与镜头就绪后开始计时；顶部可暂停镜头与结构运动、继续或重新开始，运行状态回放另行控制。拖动场景、缩放或操作对象会接管为自由探索，不自动抢回镜头；场景手势与模型标签操作会停止镜头环绕；再次开始巡游从机房重新编排。后台暂停巡游与画面运动，返回后继续；减少动态效果偏好下默认自由探索，手动开始巡游时直接切换姿态。巡游、模拟数据和镜头环绕分别控制。

自由探索支持拖动旋转、滚轮缩放、单击选择、双击对象进入其层级；右侧按钮继续深入，面包屑和“返回上级”用于返回，F 聚焦，Esc 返回。可切换总览、等轴、俯视、前视、右视。机柜层级可开合柜门、沿导轨抽出或推回服务器；进入设备会顺序完成开门、抽出和工作台切换，返回时先复原部件再回位。设备层级可在右侧展开、拖动进度、选择部件和复原；选择也可直接点击模型。左侧导航支持搜索，并按模组折叠 16 条内存、4 个风扇和 8 个盘位构件；小屏通过部件下拉框选择。子件使用显式节点映射和演示编号，不冒充真实槽位，展开时跟随父模组，复原不累计偏移。跨层选择部件先完成结构展开，再聚焦；标签默认收起，标签、阴影和自动环绕集中在“画面设置”。细节阴影默认开启，可切回标准画质；不支持所需图形能力时自动使用标准渲染。高分屏后处理与主渲染保持相同像素比；设备视图提高像素比上限、收紧阴影取景，并按部件包围盒取景。需要支持 WebGL 2 的桌面浏览器；小屏可上下浏览场景与详情。

中间工作区“态势 / 结构 / 温度 / 功耗 / 告警”切换观察模式，运行态势用柜体边线、设备指示条与图形文字标记表达；温度和功耗按各自色阶叠加到模型表面，保留金属与纹理层次。机房中不同机柜有独立颜色，进入机柜可比较不同设备；进入设备后可直接展开部件，选择内存、风扇和盘位构件并聚焦。温度色阶在机房和机柜层级表示设备进风温度（机柜取内部设备最高值），在设备内部表示预设温升与表面插值组成的示意温度场；不是实测热场或 CFD。功耗按演示预算占比着色，灰色代表未定义；告警以设备测点为依据，机柜汇总内部最高级别，不把设备进风告警归因到部件。切回“结构”可恢复原始材质。

机房扩展为 14×12 米的双排八机柜，每柜八台 2U 设备。态势页分别统计运行、维护、离线、停机和遥测质量，告警等级另行统计；图形、文字与颜色共同表达，展示优先级不改变独立状态。离线与未配置不生成数值，停机零功耗有效，过期设备保留第 44 秒的最后观测和曲线，不进入当前有效汇总。部件分级来自明确的温升模型，不冒充独立传感器告警。

右侧只展示当前所选对象的数值、图例、覆盖范围和必要操作，来源与规则折叠保存，标题固定、正文独立滚动。场景下方仅常驻紧凑回放控制，点击“趋势”按需展开曲线或事件；趋势标明当前设备，避免将设备曲线当作整个机房。左侧按机柜折叠所属设备，并提供当前设备的部件导航。

运行模式共用场景下方的 0–120 秒回放时钟，支持拖动回看、1/2/4 倍速、循环和重播。回看只影响运行状态，不倒放拆解姿态；曲线和事件只显示到当前时刻。各设备使用独立进风基线、负载与冷却响应系数。机柜和机房的功耗仅汇总有效观测的演示设备；温度取子设备进风最高值，告警取最高级别。部件温度来自显式温升假设，功耗来自分配假设；被动上盖与散热器耗电为零，未定义的盘位构件耗电保持未知。源定义见 `src/simulation.ts` 与 `src/spatial.ts`；设备对象页的“部件覆盖清单”区分已映射构件和未定义配置。

```bash
npm run build
npm run preview
npm test
```

公开内容检查仍使用 Node.js 内置模块：

```bash
node scripts/check-public.mjs
node --test scripts/check-public.test.mjs
git diff --check
```

当前限制：机房与八机柜、六十四设备均为演示配置，六十四台设备复用同一款通用 2U 结构；可选择 9 个模组与 28 个子件，仍不是完整部件清单。处理器芯片、磁盘与背板未独立建模，网卡、RAID、GPU 等配置未定义。当前模拟各设备进风温度、整机输入功耗与持续超限告警，部件云图使用显式温升假设和表面插值，不生成未定义部件的独立传感器或告警。功耗分配为演示假设，不是分项实测；累计电量只覆盖所选范围内当前具有有效观测的演示设备，并标记覆盖台数，预设冷却关系不是真实管路，不提供热流体仿真、PUE 或实际管理接口。服务器模型约 21 MB，未做面向网络发布的压缩；远景采用实例化简模，进入设备后使用详细结构；模型载入失败时使用明确提示的简化结构，尚未进行性能基准测试。
