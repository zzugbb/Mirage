## 项目介绍

浮城（Mirage）是一个面向数据中心的三维数字孪生个人项目。它以地图为入口，从园区、建筑与机房逐层深入机柜、设备和内部部件，将宏观的空间布局与微观的设备结构连接起来，构建一个可以浏览、探索和交互的数字世界。

项目规划通过机柜开合、设备抽出、结构拆解与爆炸图呈现设备形态，并结合网络、供电及冷却关系，关联功耗、温度、健康状态和告警等运行数据。借助空间定位与历史回放，让设备在哪里、如何连接、正在发生什么，都能在同一个场景中被观察和理解。

> 当前已有本地三维原型，可从机房进入机柜和设备，支持选择、镜头聚焦、旋转、缩放、9 个部件模组的爆炸展开与复原。温度、功耗和告警各有观察视图，共用一个可回放的冷却扰动模拟场景。宏观地图、完整关系网络与真机接入仍为建设目标。未部署在线演示。

## 探索路径

**中国地图 → 园区 → 建筑 → 楼层 → 机房 → 机柜 → 设备 → 部件**

空间浏览、设备结构、网络/供电/冷却关系与运行数据相互关联。超节点作为可选的设备成员关系与专题视图，成员保留各自的物理位置。

第一版先贯通：**一个园区、一栋建筑、一个机房、一个机柜、一款可拆解设备、一个可重复播放的告警场景**。模拟数据明确标记，所有视图共享对象标识与时间线。详细边界与交付步骤见 [项目设计与路线](docs/project.md)。

## 当前运行与检查

原型使用 React、TypeScript、Vite 与 Three.js。建议 Node.js 24，最低 22.12；首次安装依赖后启动本地开发服务：

```bash
npm install
npm run dev
```

打开终端显示的本地地址。默认进入室内近景并自动巡游，依次展示开门、抽出、设备展开、散热细节和复原归位，最后回到机房循环。章节进度在模型与镜头就绪后开始计时；顶部可暂停镜头与结构运动、继续或重新开始，运行状态回放另行控制。拖动场景、缩放或操作对象会接管为自由探索，不自动抢回镜头；再次开始巡游从机房重新编排。后台暂停巡游与画面运动，返回后继续；减少动态效果偏好下默认自由探索，手动开始巡游时直接切换姿态。巡游、模拟数据和镜头环绕分别控制。

自由探索支持拖动旋转、滚轮缩放、单击选择、双击对象进入其层级；右侧按钮继续深入，面包屑和“返回上级”用于返回，F 聚焦，Esc 返回。可切换室内、等轴、俯视、前视、右视。机柜层级可开合柜门、沿导轨抽出或推回服务器；进入设备会顺序完成开门、抽出和工作台切换，返回时先复原部件再回位。设备层级可在右侧展开、拖动进度、选择部件和复原；选择也可直接点击模型。细节阴影默认开启，可切回标准画质；不支持所需图形能力时自动使用标准渲染。需要支持 WebGL 2 的桌面浏览器；小屏可上下浏览场景与详情。

右侧“对象 / 温度 / 功耗 / 告警”切换观察视图，顶部状态按钮也可进入回放。温度页展示设备进风趋势与预设冷却关系；功耗页展示整机输入趋势、模型分配和回放区间累计电量；告警页展示触发、升级、降级、恢复及对象定位。三个运行页共用 0–120 秒回放时钟，支持拖动回看、1/2/4 倍速、单次或循环、重播；“脚本节点与循环设置”提供预设时刻跳转。回看只影响运行状态，不倒放拆解姿态。曲线和事件只显示到当前回放时刻，模拟规则在页面内可展开核对，源定义见 `src/simulation.ts`。设备对象页的“部件覆盖清单”区分独立模型、整组模型、逻辑条目和未登记配置。

```bash
npm run build
npm run preview
npm test
```

公开内容检查仍使用 Node.js 内置模块：

```bash
node scripts/check-public.mjs
node --test scripts/check-public.test.mjs
git diff --check
```

当前限制：机房为原创示意布局，只有一个机柜与一台代表设备；三维选择仍为 9 个模组，不是完整部件清单。处理器芯片、磁盘与背板未独立建模，网卡、RAID、GPU 等配置未定义。当前只模拟设备进风温度、整机输入功耗和一条温度告警，不生成未定义部件的测点或告警。功耗分配为演示假设，不是分项实测；累计电量仅覆盖该设备，预设冷却关系不是真实管路，不提供热流体仿真、PUE 或实际管理接口。服务器模型约 21 MB，未做面向网络发布的压缩和细节分级；模型载入失败时使用明确提示的简化结构，尚未进行性能基准测试。
